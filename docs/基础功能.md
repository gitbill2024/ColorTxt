# 基础功能

> 阅读器、侧栏、电子书转换、书签、快捷键等核心能力。安装、开发、构建与发布见 [开发构建.md](./开发构建.md)；AI 与语音朗读见 [AI功能.md](./AI功能.md)、[语音朗读.md](./语音朗读.md)。

## 侧栏文件列表：分类、排序、树状与拖放

- **分类目录与筛选**：用户维护 **`fileCategoryCatalog`**（分类名与颜色表）、当前筛选 **`fileCategory`**（`__all__` / `__uncategorized__` / 具体分类名）、排序 **`fileSort`**（`FileSortMode`：文件名/路径/大小/阅读进度/最近阅读/添加时间等升序或降序）。**打开时间**与**阅读进度**排序在切入该模式时拍快照，之后打开文件或滚动更新进度只改展示、不重排列表；再次手动切换排序（含升/降互切）才重拍。筛选非「全部」时，选择目录/拖放/选择文件等加入列表：新路径写入当前分类；**已在列表中的路径**也会改到当前分类（「未分类」则清除 `category`）。
- **列表 / 树状**：**`fileListViewMode`**（`list` | `tree`，默认 `list`）。标题「文件」右侧图标切换；树由当前筛选结果路径去掉公共父目录建成（多盘符多根并列）；文件夹 `title` 为完整目录路径，后缀「（n 文件，大小）」仅统计已加入列表的文件；**按文件大小排序**时同级文件夹按子树列表文件总大小与文件混排；初始化/切换筛选分类时：若当前打开文件在列表中则只展开其路径并定位，否则全部收起；**仅改文件项分类**（路径集合不变）不重建树、不重置展开；**列表 ↔ 树状**互切时若当前文件在列表中则定位到该项；点击文件夹仅展开/折叠，点击文件打开。树状工具栏「分类」左侧：**全部展开 / 全部折叠**（根文件夹皆收起时显示展开，否则显示折叠；展开会打开全部层级）。文件夹右键：批量分类 / 移除（确认）/ 在文件管理器中打开。展开态仅会话内内存，不持久化。
- **持久化**：上述与其它界面偏好一并写入 **`colorTxt.ui.settings`**（见 `cacheStore.PersistedSettingsData` 与 `useAppPersistence`）。
- **列表项字段**：`colorTxt.file.list` 中每条 `TxtFileItem` 除 `path` / `name` / `size` 外，可有 **`category`**（所属分类名）与 **`addedAt`**（加入列表时间，毫秒；旧数据由 `migrateTxtFileListAddedAt` 回填），用于展示与「添加时间」排序；分类与书籍元数据 **`colorTxt.file.meta`** 无关。
- **列表 UI**：`FileListPanel.vue` 使用 `useFileListCategorySort` 生成分类下拉项与计数、`useFileListSelection` 管编辑模式多选、`useFileListMenus` 管右键与分类浮层；树派生见 **`utils/fileListTree.ts`**；`ReaderSidebar` 将事件上抛至 `App.vue` 的 `onSetFilesCategory` / `onApplyCategoryCatalog` 修改 `txtFiles` 与 catalog 并持久化。
- **编辑模式落盘时机**：`fileListEditing` 为 true 时，分类变更与目录编辑先写内存；退出编辑模式（`true -> false`）后统一 `persistFileListCache()`，减少编辑中频繁写入。
- **清空行为**：筛选为 `__all__` 时走 `confirmClearFileList`，筛选为具体分类时走 `confirmClearFileListCategory`，按钮文案与行为对应为「清空 / 清空分类」。
- **更多菜单**：侧栏标题行「更多」→ **选择文件**（多选正文/电子书/书包，加入列表不打开，同拖放）→ 分隔线 → **移除失效文件**：对列表全部路径 `file:stat`，`!isFile`（含 ENOENT 不抛错）视为失效，经 `removeFileList` 移出侧栏列表（不删盘、不清阅读数据）；无失效时 toast「没有失效文件」。逐条 `stat` 期间以 **`appLoading.with("检查中")`** 显示全局蒙层。
- **拖放**：见 **`useAppWindowBindings.ts`**：侧栏列表区域合并进文件列表（正文 + **`.ctz` / `.ctzx` 书包批量导入**，见 **「彩读书包」→ 侧栏批量导入**）；**非侧栏**区域打开拖入列表中第一个支持的文件（`isSupportedBookPath` 或彩读书包，后者走 `openFilePath` → 导入后打开，同「打开文件」）。
- **选择目录 / 选择文件**：目录枚举含 `.txt` / `.md` / 电子书 / **`.ctz` / `.ctzx`**；「选择文件」为多选对话框。渲染侧按 `looksLikeZipBookPackCandidate` 分区——正文走 `mergeTxtFileLists`，书包走批量导入（不把 `.ctz` 本身当可读正文进列表）。

## WebDAV 同步

跨设备同步主窗配置、书包与找书数据。连接配置在「设置 → WebDAV」（主窗与找书共用）；密码进 secrets vault（`webdav.password`），**不**写入 `colorTxt.ui.settings`。

### 远端目录（默认根名 `ColorTxt`，可改）

```text
ColorTxt/
  Main/settings.json          # colorTxt.ui.settings（已剥离语音 API 密钥）
  Main/replaceRules.json      # colortxt:replaceRules:app
  Main/reader-backgrounds/    # 自定义阅读区背景图（按文件名；主窗/找书共用）
  Books/*.ctz|*.ctzx          # 书包
  FindBook/ui-reader.json     # 阅读/编辑/语音/配色相关 ui 子集
  FindBook/settings.json      # colortxt.findBook.settings
  FindBook/replaceRules.json
  FindBook/bookshelf/{书名_作者_hash}.json  # 一书一文件（书名_作者命名，避免非法 id）
  FindBook/bookshelfCategory.json / bookshelfSort.json / searchHistory.json
  FindBook/bookSource.json    # 书源库
```

冲突策略：**一律覆盖**（不比较时间）。书架上传/更新按内容 hash / 远端 mtime **增量**跳过未变更本；上传会删除远端孤儿书文件；更新**保留**本地独有书。书源「更新」走 `importCommit` **合并**（不删本地多出的源）。自定义背景图按 **文件名 + 大小** 增量上传/下载（同名同大小则跳过）；上传成功写入 JSON 后再删远端孤儿；下载先拉变更的文件再覆盖本地元数据。

### 主窗入口

- 启用后侧栏配色上方 **WebDAV** → 面板：列出 `Books/`（过滤文件名、按上传时间/文件名/大小排序、刷新；单项/批量串联下载，加入侧栏「文件」列表）；底栏「上传配置 / 同步配置」（含 `Main/reader-backgrounds/` 自定义背景图增量）。
- 底栏路径菜单最上：「上传书包」（当前书，含阅读进度；路径旁显示上传进度）/「同步书包」（按同名下载并打开；路径旁显示同步进度）。**同步书包**只打开当前书，不因此把路径加入「文件」列表。

### 找书入口

- 顶栏主题色左侧 **WebDAV** 弹出菜单：
  - **上传 / 同步书架**：`FindBook/bookshelf/{书名_作者_*.json}`（一书一文件、增量）及分类 / 排序
  - **上传 / 同步书源**：`FindBook/bookSource.json`（同步为合并）
  - **上传 / 同步设置**：`ui-reader.json` / `settings.json` / `replaceRules.json` / `searchHistory.json`（自定义背景图与主窗共用 `Main/reader-backgrounds/`，增量）

## 电子书解析与转换（`src/renderer/src/ebook`）

渲染进程在**打开电子书**时将其转为 UTF-8 的 Markdown 正文（`.md`），可选写出插图目录；路径判定与让出 UI 在 `ebook/` 根目录，**格式解析、目录注入与写出**在 `ebook/convert/`，与 `shared/ebookExtensions.ts` 中的扩展名列表、`shared/ebookConvertPaths.ts` 中的默认输出子目录名保持一致（主进程目录扫描、壳层打开路径判定依赖前者）。

### 支持的格式与入口

| 扩展名            | 说明                                                                                                               |
| ----------------- | ------------------------------------------------------------------------------------------------------------------ |
| `.epub`           | ZIP 容器，走 `convert/parseEpub.ts`                                                                                        |
| `.mobi` / `.azw3` | 先尝试 `tryConvertZipAsEpub`（部分 AZW3 实为 ePub 封装）；否则经 `convert/mobi/foliateMobi` 抽取后由 `convert/parseMobi.ts` 转产物 |
| `.fb2` / `.fbz`   | FB2 或 ZIP 内单 FB2，`convert/parseFb2.ts`                                                                                 |
| `.pdf`            | `pdfjs-dist` 文本层 + **`getOutline()` 书签目录**，`convert/parsePdf.ts`                                                   |
| `.chm`            | `convert/parseChm.ts`；底层块读取与 LZX 在 `convert/chm/chmArchive.ts`、`convert/chm/lzxDecode.ts`                                         |

`ebookFormat.ts` 提供 `isEbookFilePath`、`isMarkdownFilePath`、`isSupportedBookPath`（TXT、`.md` + 上述电子书扩展名）、输出用基名 `ebookSourceFileBaseForOutput`（含 Windows 非法字符净化 `sanitizeWindowsFilenameSegment`）。拖放 / 关联打开时 `useAppWindowBindings` 用 `isSupportedBookPath` 过滤正文书籍；**另**接受 **`.ctz` / `.ctzx`**（`looksLikeZipBookPackCandidate`），由解析校验是否为彩读书包（见 **「彩读书包」**）。主进程 `ipcHandlers` 的目录枚举用 `EBOOK_DOT_EXTENSIONS` 与 `.txt`、`.md`、**`.ctz` / `.ctzx`** 一并收集；壳层双击打开路径另见 `isSupportedShellOpenPath`（含 `.ctz` / `.ctzx`）。

### Markdown（`.md`）

- **打开**：`resolvePhysicalTextForOpen` 对非电子书路径直接流式读盘（与 `.txt` 相同），`physicalReaderPath` 指向 `.md` 原文件。
- **章节**：仅识别 ATX 标题（`#` … `######`，行首最多 3 个空白）；`markdownBlockContext` 在围栏代码块与 4 空格/TAB 缩进代码块内跳过 `#`；**结构扫描**基于**物理行**（避免「行首缩进」展示层误判）；侧栏 **`title`**：只读取已去 `#` 的**展示行**（含文本替换 / 转换）；编辑态展示行仍带 ATX，经 **`detectMarkdownHeading`** 取纯标题（侧栏不出现 `#`）；侧栏 `headingLevel` 每级缩进 10px；有子级的父标题可折叠（默认全部展开；标题「章节」右侧 **全部展开/全部折叠**）；阅读换章或滚入当前章时自动展开其祖先；标题行「更多 → 复制目录」按层级空格缩进写入剪贴板（一行一标题，完整目录）；顶栏「章节匹配规则」对 `.md` 禁用。
- **插图（只读）**：`markdownImages` 用 marked **`Lexer.lexInline`** 解析独占行 `![alt](url)`（与内链同一套，不做非标准兜底）。`readerImageViewZones` 删源行并插 ViewZone；zone 总高度 = **`markdownImageHeightPx`**（设置 → 阅读 → Markdown → 插图高度，默认 100，范围 50–1000，步进 50）+ **`lineSpacingPx`**（底部空隙对齐正文段间距；改段间距 / 插图高度时 **`syncReaderImageViewZonesLineSpacing`**）；`https:` URL 直链；编辑模式不处理。相对路径经 **`resolveMarkdownAssetAbsPath`** 按 `/` 分段 `joinFs`。
- **转换写出路径转义**：`ebookMarkdownEmit.escapeMdUrl` 在块级图、链接图标、外链目标中转义 `\` / `(` / `)`；路径含空白时用 `<…>`。磁盘文件名本身不改，仅 md 语法层转义。

- 基于 [libmspack](https://github.com/kyz/libmspack)（GNU GPL）移植了一套 JavaScript 实现，以支持对 `.chm` 格式的解析
- 其他电子书格式的解析，主要参考 [foliate-js](https://github.com/johnfactotum/foliate-js)（MIT）

### 转换管线与输出布局

- **调度**：`convert/convertEbookToMarkdown.ts` 中 `convertBookBufferToArtifacts(absSource, buffer)` 按源路径后缀分派各 `parse*.ts`，得到 `EbookMarkdownArtifacts`（`convert/ebookTypes.ts`：`utf8` + 可选 `imageWrites`，每项含相对路径与 `ArrayBuffer`）。
- **写出**：`writeEbookConversionArtifacts` 将正文写入目标 `.md`，插图按 `relativePath` 写到与 `{basename}.md` **同目录**下；约定目录名为 **`{basename}.Images/`**（由 `imagesDirAbsBesideConvertedMd` 与相对路径前缀一致）。无插图时会 `removePath` 清理残留插图目录。
- **输出格式**：正文为 `{basename}.md`；块级图为独占行 `![…](rel)`（`rel` 经 `escapeMdUrl`），行内链为 `[…](#frag)` / `[![…](icon)](#frag)`（icon 同样转义），锚点为 `<span id="…"></span>`。
- **HTML 换行**：EPUB / MOBI / CHM 将 `<br>` / `<hr>` 作为行边界写成独立 md 行（与浏览器 / Foliate 一致）；`<p>` 等块级元素各占一行。源 HTML 中的排版空白仍折叠。部分书用「单 `<p>` + 大量 `<br>`」排轻小说对白，不能把 `<br>` 收成空格。**需重新转换**（或删缓存 `.md`）后生效。
- **让出 UI**：`ebook/yieldToUi.ts` 用 `setTimeout(0)` 在长时间解析前后打断，便于底栏「转换中…」等状态刷新；`readBookAsArrayBuffer` 与 `ensureEbookMarkdown` 内多处调用。

### 输出路径与缓存

- **目标 `.md` 路径（写入与严格缓存的参照）**：
    - `resolveConvertedMdOutputPaths`：基名为源文件名整段（经 `ebookSourceFileBaseForOutput` 净化，如 `abc.epub` → `abc.epub.md`）。
    - `ebookConvertOutputDir`（`colorTxt.ui.settings`）**非空**时输出到该目录；**空字符串**表示与**源书同目录**。
    - 新安装或尚无该键时，默认 **`app.getPath("userData")/ConvertedTxt`**（目录名见 `shared/ebookConvertPaths.ts`，preload `getDefaultEbookConvertOutputDir`；缓存文件扩展名为 `.md`）。
- **彩读书包解压目录**：设置项 **`bookPackUnpackDir`**（「设置 → 常规 → 书包」→「书包解压目录」）；**非空**时解压到该绝对路径；**空串**或未配置时回退 **`userData/UnpackedBooks`**（`UNPACKED_BOOKS_DEFAULT_SUBDIR`）。首次启动若设置 JSON 无该键，写入默认路径并持久化。见 **「彩读书包」**。
- **彩读书包默认密码**：设置项 **`bookPackPassword`**（「设置 → 常规 → 书包」→「书包默认密码」）；**默认空串**表示不设密码，导出 **`.ctz`**。非空时导出 **`.ctzx`**（**CTZE** 整包加密，AES-256-GCM + PBKDF2，见 `readerBookPackCrypto.ts`）。导入加密包时先尝试该密码（侧栏批量另作临时密码本起点）；缺失或错误则弹出密码输入框。明文 `.ctz` 仍可直接导入（忽略该密码）。
- **严格缓存命中**：`ensureEbookMarkdown` 在同时满足下列条件下直接复用、不再解析：`file.meta` 中 **`convertedMdPath` 与当前策略算出的目标路径一致**（与 `resolveConvertedMdOutputPaths` 逐路径规范化比较）、**`sourceMtimeMsAtConvert` 与当前源 `mtimeMs` 一致**，且对该路径 `stat` 仍为普通文件。
- **和解查找（路径无效统一处理）**：
    - **何时视为「路径无效」**：meta 中无 `convertedMdPath`（空或未写入），或「有路径但严格缓存未通过」——共用同一套和解逻辑。
    - **何时执行和解**：仅当 **无记录路径**，或 **记录的源 mtime 与当前源 `mtimeMs` 一致（`mtimeStable`）** 时才和解，避免源书已更新仍复用旧的 `{basename}.md`。
    - **实现**：**`findReconciledConvertedMd`** 对候选路径规范化去重后依次 `stat`，**第一个存在的普通文件**即复用结果。
    - **候选顺序**：若 `mtimeStable` 且 meta 曾有非空路径，**优先该路径**（例如输出目录变更后旧文件仍留在原记录路径）；然后 **当前设置的输出目录**（非空时）下的 `{basename}.md`；**源书同目录**下的 `{basename}.md`；**默认 `userData/ConvertedTxt`** 下同名文件。
    - **无命中**：完整转换 `readBookAsArrayBuffer` → `convertBookBufferToArtifacts` → `writeEbookConversionArtifacts`（写出路径为当前策略下的 `convertedMdPath`）。
- **meta 写回与打开路径**：
    - `useAppFileSession.resolvePhysicalTextForOpen` 在 `ensureEbookMarkdown` 后调用 `setEbookConvertedMeta`，写入 `convertedMdPath` 与 `sourceMtimeMsAtConvert`，并 `persistFileMeta`。
    - 流式管道使用的 `physicalPath` 为转换后的 `.md`；**逻辑上书路径**仍为源电子书路径；`currentFile`、会话、最近打开以**源书路径**为键。

### Markdown 内链/锚点与阅读器衔接

转换输出在 `.md` 中使用标准 Markdown 扩展语法（非旧版 `<<ID>>` / `<<A>>` / `<<IMG>>` 特殊标记）：

- **`<span id="frag"></span>`**：锚点（fragment 经 `EbookMarkdownFragmentRegistry` 去重，如 `f_1_2`、`fr_1_2`、`toc_1`）。
- **`[可见文案](#frag)`** / **`[![alt](icon)](#frag "title")`**：内链；`title` 属性为悬停提示（写入时取 `title` 或 `alt`）；脚注 noteref 为跳转链 + 同行尾部回跳 `fr_*` span；脚注序号可写 **`[[1]](#m1 "1")`**。
- **独占行 `![alt](rel)`**：块级插图；阅读器删行后插 ViewZone。

**内链/外链解析（`markdown/markdownLinkShared.ts`）**：

- 扫描基于 **marked `Lexer.lexInline`**（与 AI 助手 Markdown 规则一致），替代手写正则。
- 入口：`scanMdInternalLinkAt` / `scanMdExternalLinkAt` / `scanNextMdLinkAt` / `scanMdInternalLinksOnLine`；label 内嵌 `![alt](href)` 时补 **平衡 `]`** 与 marked 式 **`findClosingBracket(…, '()')`**，支持 href / 相对路径中含 `[]`、空格。
- 扫描时若 `[` 属于块级/行内图 `![…](…)`，先整段跳过，避免把其中的 `[](https://…)` 误剥成外链（留下孤立 `!`）。
- 转换侧 **`ebookStemOnlyMdLinks`**、**`ebookTitleMatch`**、**`ebookSpineLineMatch`** 与阅读器 **`markdownInternalLinks`** 均复用上述扫描器。

**链接图标 vs 块级插图（转换分流）：**

| 结构 | 输出 |
|------|------|
| `<a>` 内仅 `img` / `noteref` 上下文内小图 | 行内 `[![…](icon)](#frag)` |
| `<figure>` 内独立图、段落中无 `<a>` 包裹的 `img` | 独占行 `![…](rel)` + ViewZone |

**格式覆盖：** EPUB、MOBI/AZW3、FB2/FBZ 已对齐；CHM、PDF 亦输出 `.md`。**需重新转换**（或删缓存 `.md`）后阅读器才生效。

### 嵌入目录与 ATX 章节注入

阅读器侧栏「章节」仅识别 ATX 标题（`#` … `######`，见 **`markdownChapter.ts`**）。转换阶段从各格式**嵌入目录**写入 ATX 与 `<span id="toc_N"></span>`，使章节列表尽量与源书 TOC 一致（不另写独立目录块）。

**写入形态**（`convert/ebookTocAnchorInjection.ts`）：

- `<span id="toc_N"></span>` 与 ATX 标题分两行；`applyLineMutations` 按行号降序应用，保证同索引先写标题、再 insert 锚点（锚点在上）。
- 节内已定位到标题行且纯文本与目录**完全一致**时：在该行 **replace** 升 ATX（保留行首已有 id span）。
- 节首 **fallback**（无精确匹配）：插入**完整目录标题**（如 `# 卷一 周纪一`）；节首为插图/正文时 `shouldReplaceLineWhenInjectingTocHeading` 为 false，**insert** 不覆盖原行。

**标题匹配（EPUB / MOBI / AZW3，共用 `convert/ebookSpineLineMatch.ts`）**：

- `findTitleLineInSpineSection`：**仅精确匹配**——节内某行去 span / 内链后的纯文本须与目录标题完全相同。
- **已移除**「包含」匹配（`want.includes(plain)`）与按标点拆段的子串匹配，避免目录为 `卷一 周纪一`、正文为两行 `卷一` + `周纪一` 时误将 `卷一` 升为 `# 卷一`。
- `resolveTocInjectLineIdx` **不再**用 fragment 锚点行作为升 ATX 目标；无精确匹配即走节首 fallback。侧栏以目录原文为准，正文可能与标题重复，属可接受取舍。
- 搜索范围限定在**当前 spine 节**（`EpubSpineSectionRange`），按 `tocOrder` 与 `searchStartByStem` 顺序处理多项。

**各格式目录来源与注入入口**：

| 格式 | 目录来源 | 注入 |
| ---- | -------- | ---- |
| EPUB | `nav` / NCX → `ebookEpubNav` → `flattenFoliateStyleTocTree` | `injectEpubTocAnchorsIntoLines` |
| MOBI | foliate `book.toc`；缺失时 `buildMobiTocTreeFromNcx` | `injectFoliateMobiTocIntoLines`（`convert/parseMobi.ts`） |
| AZW3 | 与 MOBI 相同：`convert/convertEbookToMarkdown` 先 `tryConvertZipAsEpub`，否则 **`convertMobiToArtifacts`**（KF8 / `convert/mobi/foliateMobi.js`） |
| PDF | `pdfjs-dist` **`doc.getOutline()`**（与 foliate-js 一致，读 PDF Document Outline / 书签） | `injectPdfOutlineIntoLines`（`convert/parsePdf.ts`） |

**EPUB 目录 href 映射**（`convert/ebookEpubNav.ts`）：

- `parseNavDocument` / `parseNcxDocument` 内 **`resolveUrl(navPath|ncxPath, href)`** 产出 **OPF 包根相对路径**（如 `Text/part0001.xhtml`），与 foliate-js 一致。
- 映射 spine 短键 **`epub-NNNN`** 时须相对 **`opfDir`**（OPF 所在 ZIP 目录，如 `OEBPS`）做 `resolveInZip`；**勿**再用 nav 文件所在目录（如 `OEBPS/Text`）二次 resolve，否则 `Text/…` 会错成 `Text/Text/…`、目录项全部无法注入（侧栏无章节）。
- spine 预扫描 **`zipPathToLinkStem`** 保证目录页可链接到尚未遍历的文档；跨章 stem-only 内链 **`[…](#epub-NNNN)`** 由 **`ebookStemOnlyMdLinks`** 后处理注入目标节 `<span id>`。

**PDF 专项**（`convert/parsePdf.ts`）：

- CMap / JBIG2·JPEG2000 wasm / 标准字体 / ICC 使用随包的 **`pdfjs-dist`** 资源（开发态 `/pdfjs/`，打包后相对页面的 `pdfjs/`），不请求 jsDelivr；否则 CSP 会拦截中文 CMap，转换停在「转换中」。
- 文本层用 `getTextContent`；插图按 PDF **XObject** 抽取（同一对象只解码一次：JPEG 原样写出，Flate/Indexed 按调色板展开，JPX/JBIG2 用 `pdfjs-dist` image_decoders + wasm）。**不**逐页 `getOperatorList`（那会把整页文字路径搬到主线程，比 Foliate 的 `page.render` 慢很多）。`disableFontFace` 避免缺系统字体时 FontFace pending。蒙版与单色铺底（Indexed hival=0）不导出。
- 每页正文拆为独立 `lines` 行（非整页压成一行），便于按行精确匹配。
- 页内优先**整行精确匹配**书签标题；同页多节辅以书签 dest 的 **Y 坐标**（`findPdfLineByDestY`，仅考虑短行）。
- **仅精确匹配**时对命中行 replace 升 ATX；**Y 定位**时 **insert** 标题，**不 replace**，避免吞掉正文行。
- 标题被 PDF 文本层拆成相邻两行时：拼接后精确匹配，升 ATX 并清空续行（如「…开把」+「簧」）。
- 无匹配则**跳过**该书签项，不在页内堆叠多个 fallback 假标题。
- 纯页锚点 `<span id="pdf-pN">` 行不直接升 ATX（与 MOBI `filepos` 锚点行处理思路一致）。

**MOBI 历史注意点**：目录项须**标题匹配优先**于 fragment；纯 `filepos` / 锚点独占行在下一行升 ATX，避免 `#` 写在 span 同行。

底栏对源电子书提供 **「重新转换」**（`forceEbookConvert`）；修改注入逻辑后须重新转换方更新已缓存 `.md`。

### 黏性章节条（sticky scroll）

Monaco `stickyScroll` + `chapterStickyScroll.ts` 的 DocumentSymbolProvider 在阅读区顶部显示当前章节大纲（多级目录时多层叠放）。**设置 → 阅读 → 启用粘性章节标题**（**`stickyChapterTitleEnabled`**，默认 **开启**，持久化于 **`colorTxt.ui.settings`**）控制是否显示；关闭后 Monaco `stickyScroll` 禁用，正文内章节标题行内装饰（`.chapterTitleLine`）不受影响。`ReaderMain` 在 **`streamLoading`** 期间亦强制关闭 sticky，避免加载旧文件时黏性标题残留。找书阅读器用 `AppModal` `v-if` 开关时会销毁/重建 `ReaderMain`：语言只需全局注册一次，但 DocumentSymbolProvider **须随实例重新注册**（卸载时 dispose），否则第二次打开粘性标题失效。

`ReaderMain.setChapters` 在更新章节装饰与文档符号后调用 **`scheduleStickyChapterScrollRefresh`**（内部 **`refreshStickyChapterScrollWidget`**：短暂关闭再开启 sticky；仅在 sticky 应为开启时执行），避免重新加载后黏性条仍用旧渲染、标题样式（颜色/字号）未与正文 `.chapterTitleLine` 同步的问题。

**程序性跳转与黏性条留白**（`reader/readerViewportAnchor.ts`）：

- 共用 **`computeScrollTopForLineAtViewportSlot`**：`revealLineNearTop` 后将目标行顶沿对齐视口「从上往下第 N 条字高带」。
- **章节列表**（**`jumpToChapter`**）：尺关闭时 **N = `headingLevel`**（1 级 → 第 1 条字高，4 级 → 第 4 条字高），避免深层目录跳转后标题被多层黏性条遮住。**阅读尺开启时**改为把章节标题行滚到视口（扣粘性条）垂直中间，并作为聚焦带中间行（`scrollChapterTitleToRulerFocus`）。
- **书签列表**（**`jumpToBookmarkLine`**）：固定 **N = 2**（**`READER_BOOKMARK_JUMP_SLOT_FROM_TOP`**），与单层黏性条时的历史留白一致；添加书签采样行亦对齐第 2 条字高带。
- **只读↔编辑 / 格式化恢复**：**N = 2**（**`READER_VIEWPORT_RESTORE_SLOT_FROM_TOP`**），与书签跳转相同，非章节层级动态计算。

**翻页重叠完整行**（`ReaderMain.scrollByPageStep`；空格 / `PageDown` / `PageUp` / 定时滚动「一屏」共用）：

- 相邻两页重叠一条**完整视觉行**，避免多层粘性标题盖住上一页最后一行。
- **向下**：Monaco **`getVisibleRanges`** 最后一条（完整可见 view line 转成的模型 Range；软换行边界列退一列）→ **`getTopForPosition`** 对齐到落点 **`predictStickyChapterScrollHeight`** 之下（不能用当前 DOM 条高：落点层数可能变）。
- **向上**：**`getTargetAtClientPoint`** 取当前粘性条下方第一条未被挡住的完整视觉行，将其底对齐到视口底。
- 滚动类型走设置 **`monacoSmoothScrolling`**；停稳后再按 **`getStickyChapterScrollHeight`** / 实际视觉行高校正。连按翻页会取消上一轮校正。
- 视口过短或无法前进至少一行时，回退步长为 **视口 − 条高 − 一行**（向下回退仍用落点预测条高）。
- 找书阅读器章内翻页走同一函数；到章边界后再翻页才切章（见 [书源找书.md](./书源找书.md) → **§6.7**）。

`ReaderMain.vue` 载入 `.md` 后：

- `applyEmbeddedImageAnchors`：`collectBlockMarkdownImageLines` → ViewZone。
- `applyMarkdownInternalLinks`：`stripMdInternalLinksFromText` 剥离 `<span id>` / 内链语法，安装侧车（`id → 物理行`、点击区间、行首链内 label）。
- 含 `iconRel` 的内链用 `.readerEbookLinkIcon` 与 `colortxt-local://` 背景图；图标路径经 **`resolveMarkdownAssetAbsPath`** 解析，加载失败时回退 **`.readerEbookLinkIcon--builtin-link`** 占位；纯文字链为 `.readerEbookInternalLink` 下划线。
- 与展示行↔物理行映射配合：`ebookDisplayLineToPhysical` / `ebookAnchorPhysicalToDisplay`（插图删行后映射须同步）。
- **大文件性能**：脚注极多时加载在侧车中批量处理；点击在 `editorHost` 捕获阶段统一命中；装饰仅注册视口 ± 约 80 行。

## 全屏阅读与浮动 UI

全屏或**极简视图**时顶栏、底栏、左侧章节/文件侧栏默认隐藏，靠窗口边缘**感应区**呼出；移出对应面板区域后收起；在**阅读区所在 `.layout`** 上按下鼠标时也会一并收起已打开的浮动层（点在已展开侧栏内除外）。实现集中在 `src/renderer/src/composables/useAppReaderChrome.ts`（`chromeAutoHide = isFullscreenView || isMinimalistView`），边缘像素与右侧滚动条「非唤起带」在 `src/renderer/src/constants/appUi.ts`（`FULLSCREEN_*_EDGE_PX`、`FULLSCREEN_RIGHT_SCROLLBAR_GUTTER_PX` 等）。唤起与收起均有短过渡（顶/底栏 **140ms**、侧栏 **180ms**，方向与滑入相反）；收起用 Vue **`Transition`** 延后 `display: none`，避免一关就瞬间消失。非自动隐藏模式（普通窗口）不套该过渡。浮动顶栏 / 底栏 / 侧栏均有投向阅读区一侧的阴影（`6px` / `28px` / `rgba(0,0,0,.45)`，方向随边缘）。指针静止约 **2 秒**后隐藏系统光标（`fullscreen--cursorHidden`）；顶/底/侧栏浮出、正在拖侧栏、或**编辑模式**时不藏。

### 统一交互模型

1. **`document` `mousemove`（由 `useAppWindowBindings` 注册）**  
   仅当 **`chromeAutoHide`** 为真、**该浮动层尚未显示**、且**未按下鼠标按键**时，根据指针是否进入对应边缘感应区决定是否唤起。按住拖到边缘（选区 / 拖动滚动）或刚进入全屏时，松手后若指针仍在感应区内也不立刻唤出，须先离开各边缘感应区再移入才会出现。**有蒙版弹层时三边都不唤起**（相对 `useAppReaderChrome` 挂载时多出来的 `registerModal` 层、灯箱等 `pushEscBeforeModal` 层、以及 `appLoading` 蒙层；找书阅读器整窗本身就是一层 AppModal，不计入）：
   - **顶栏**：`clientY` 不超过顶缘厚度，且不在右侧 gutter 内（避免误触 Monaco 固定滚动条一带）。
   - **底栏**：`clientY` 不低于「视口高度 − 底缘厚度」，且不在右侧 gutter 内。
   - **侧栏**：`clientX` 不超过左缘厚度。  
     一旦某层已显示，mousemove 上若指针已不在该面板（及对应 Teleport 白名单）内则收起。**例外**：`openSidebarSearch` / `toggleSidebar` 等快捷键打开浮动侧栏时（`revealFullscreenSidebar`），指针尚未进入侧栏前不因「不在侧栏上」而收起，避免阅读区一动鼠标就把刚弹出的侧栏收回；指针进入侧栏后恢复离开即收。点阅读区（`.layout` pointerdown）仍会收起。

   **蒙版弹层打开**：相对挂载基线多出来的 `registerModal` 层、灯箱等 `pushEscBeforeModal` 层、以及 `appLoading` 蒙层会立刻收起已浮出的顶栏/底栏/侧栏。顶栏打开的设置/配色等蒙层带 `data-fullscreen-header-float`，`mouseleave` 不会收起顶栏，因此与侧栏（点 WebDAV/设置后因指针落到蒙层而 `mouseleave`）对齐时要按模态栈收起。侧栏文件「分类管理」等 **AppModal** 也走这条收起；`FileListPanel` 只关掉 Teleport 菜单/下拉，**不**把该弹窗一并关掉。

2. **面板根节点 `mouseleave`（在 `App.vue` 模板中绑定）**  
   仅当 **`chromeAutoHide`** 为真时尝试收起对应 `showFullscreen*`：
   - 顶栏：`appHeaderWrap` → `onFullscreenHeaderMouseLeave`
   - 底栏：`appFooterWrap` → `onFullscreenFooterMouseLeave`
   - 侧栏：`sidebarPaneWrap` → `onFullscreenSidebarMouseLeave`  
     浏览器只在指针离开**该元素及其子节点**时触发。若当前有可点外关闭的弹出菜单（`hasDismissibleOverlay`，如顶栏「字体 / 更多 / 转换」、侧栏「更多」、底栏路径/编码菜单），**移出面板不收起**，避免 Teleport 菜单悬空或「转换」等非 Teleport 菜单随面板一起被 `v-show` 拆掉。菜单关掉后，若指针已不在该面板上，再按最后指针位置收起。

   **指针离开窗口**：`document` `mouseout` 且 `relatedTarget == null` 时强制收起（快速擦过边缘移出窗口、或移到系统标题栏时，指针可能从未进入面板，不会收到面板 `mouseleave`）。**例外**：正在输入法合成（`compositionstart`…`compositionend`），或焦点仍在当前浮层内的文本框时不收起——IME 候选词弹框是系统原生窗口，出现在指针下方会触发同样的 `mouseout` / `mouseleave`，并可能让 `elementFromPoint` 为空。

3. **`.layout` `pointerdown.capture`（`App.vue` / 找书 `findBookReaderBody`）**  
   chrome 自动隐藏时先于 `useAppFullscreenReaderLayout` 的 `onLayoutMouseDown` 调用 `dismissFullscreenPanelsOnLayoutPointerDown`：将顶栏、底栏、侧栏的 `showFullscreen*` 一律置 `false`（已为 `false` 则无影响）。**须用捕获**：点击模式会在阅读区 `editorHost` 捕获阶段 `stopImmediatePropagation`，冒泡到 `.layout` 收不到。点在阅读区时，菜单会在捕获阶段先关，随后面板收起；若实际收起了浮动层，本轮点击模式松开不翻页（拖动仍可滚正文）。顶栏、底栏挂在 `.layout` 之外，能命中 `.layout` 的按下即表示未点在顶/底栏上。侧栏在 `.layout` 内：若侧栏处于展开态且事件目标落在侧栏根容器子树内（含沿 **ShadowRoot.host** 向上的判定，与正文区滚轮转发一致），则**不**收起，避免在侧栏里点选时误关。

4. **层间互斥**  
   `canShowFullscreenPanel` 保证同一时刻只有一种浮动层可通过边缘被唤起（避免叠在一起）。

5. **Esc（`handleReaderChromeEscape`）**  
   极简 / 全屏下按层关闭，一次只关一层。顺序大致为：
   1. **输入框失焦**：焦点在 `input` / `textarea` / `contenteditable` 时只 `blur` 并吞掉 Esc（`utils/escapeBlurTextField.ts`，入口捕获监听，菜单与蒙版内同样）。不含文件重命名、阅读器 Monaco（查找栏输入除外）、加载蒙层中止 Esc。
   2. **蒙版弹层**：`registerModal`（设置 / 配色 / 词典 / 翻译 / 笔记等）与灯箱、角色卡放大、思维导图 / 词云全屏等 `pushEscBeforeModal` 层、以及 `appLoading` 蒙层。找书阅读器整窗本身是一层 AppModal，不计入挡层。
   3. **弹出菜单**：顶栏「更多 / 字体 / 转换」等可点外关闭层（`hasDismissibleOverlay`）；侧栏高亮词 `+N` 展开、AI 助手历史 / 导出菜单等同属此层。
   4. **Monaco 查找栏**（`.find-widget`）。
   5. **浮动顶栏 / 底栏 / 侧栏**。
   6. **退出全屏**（仅全屏）：须在约 2 秒内再按一次 Esc；第一次顶部胶囊提示改为「再按 1 次 ESC 退出全屏」（与进入全屏时同一套 `fullscreenTip`）。按住不放的 `repeat` 不计第二次。Esc **不**退出极简。进入全屏时胶囊文案为「按 2 次 ESC 退出全屏」。

   让出：文件重命名（取消重命名）；编辑态焦点在 Monaco 内（查找栏除外，补全等仍交给编辑器）。弹出菜单关 Esc 时 `stopPropagation`，避免同一按键既关菜单又收浮动栏。

6. **进入 / 退出全屏**  
   进入全屏时收起已浮出的顶栏/底栏/侧栏（极简下点「全屏阅读」时顶栏往往已显示，且指针仍在按钮上，不会走 `mouseleave`）。收起后在指针离开各边缘感应区前不再唤起。主进程广播非全屏或原生退出全屏时，`dismissFullscreenChromeForNativeExit` 会清空各 `showFullscreen*`、全屏提示计时器与 Esc 退出确认，避免 UI 状态残留。

   **macOS 退出全屏保持阅读位置**（`useFullscreenViewportPreserve`；主界面 `App.vue` 与找书 `FindBookReaderPanel` 各挂一份。Windows / Linux 为空操作，不改原路径）：系统全屏进出带 Space 缩放动画，过渡帧里 Monaco 视口底行会漂，进度按底行会被写成更靠后。仅 macOS 在过渡期间冻结进度，并用退出前的 Monaco `saveViewState` 在 chrome 回到文档流后再 `restoreViewState`。应用内退出时，`enterOrExitFullscreenView` 在 `setFullscreen(false)` 之前调用 `prepareFullscreenExit`。原生绿灯或 `onFullscreenChanged(false)` 由 `useAppWindowBindings` 先 `ensureExitAnchorBeforeChromeChange`，再关全屏 UI，然后 `restoreAfterLeave`（两帧布局 + 约 32ms）。全屏中的窗口 `resize` 会先冻住上一帧稳定 viewState；若 1.2s 内仍处于全屏，视为误报并解冻。冻结时 `suppressViewportProgressUpdates` 拦住 `useAppReaderUiPrefs` 的视口行 / 百分比，以及 `useAppChapterNavigation.onProbeLineChange`，过渡帧不写入进度与 meta。全屏进出不改展示行映射，因此直接用原生 viewState，不走物理行锚点。`ReaderMain.captureEditorViewState` 只做内存快照，不落盘。

7. **顶栏与查找**
   Monaco 查找控件展开时，`updateFullscreenHeaderHover` 内若 `isFindWidgetRevealed()` 为真会强制收起顶栏，避免与查找条布局冲突。查找栏 tooltip、↑↓ 搜索历史与快捷键让出见 **「Monaco 查找栏」**。

8. **侧栏宽度**
   非全屏时侧栏仍可拖拽改宽；全屏浮动侧栏宽度仍用同一 `sidebarWidth` 状态（`startResizeSidebar` / `endSidebarResize` 等未改）。拖条视觉与 Monaco Diff 分栏 sash 对齐（`--app-sash-*`：4px、`ew-resize`、悬停约 300ms 后显蓝条并渐隐，拖拽中保持高亮）。多主窗口下其它窗口同步 settings 时 **`loadPersistedSettings({ applySidebarWidth: false, applyShowSidebar: false, applyMinimalistView: false, applyReaderUiPrefs: false })`**，避免侧栏开关/改宽、极简视图以及阅读/编辑/语音朗读相关 UI 实时同步到其它窗口。

### 顶栏 UI

全屏时 `AppHeader` 传入 `inFullscreen`。顶栏 **`MinimalistViewButton`**（全屏按钮左侧）始终显示：普通态进入极简，已进入时为激活的「退出极简视图」。全屏浮动顶栏同样保留该按钮，但禁用。侧栏无独立顶栏按钮，用 **`toggleSidebar`** 快捷键（默认 **`Ctrl+B` / `Command+B`**）；极简 / 全屏下只唤出浮动侧栏（见下「极简视图」）。

#### 响应式收纳（`useAppHeaderLayout`）

### 极简视图

窗口内隐藏顶栏、底栏与整块侧栏（含活动栏），阅读区撑满窗口；**不**进入系统全屏，也**不**套用全屏正文百分比居中留白。边缘感应、浮动层收起、光标静止隐藏与全屏共用 `chromeAutoHide`。

- **入口**：顶栏 **`MinimalistViewButton`**（全屏按钮左侧；`enter_minimalist_view.svg` / 已进入时 `leave_minimalist_view.svg` 并激活）。默认快捷键 **`F10`**（`toggleMinimalistView`）。全屏时按钮禁用，`F10` 亦不切换。`ESC` 先关蒙版 / 菜单 / 查找栏 / 浮动面板，**不**退出极简。
- **侧栏快捷键**：极简 / 全屏下 **`toggleSidebar`**（默认 **`Ctrl+B` / `Command+B`**）只唤出浮动侧栏，**不**切换、也**不**写入 `showSidebar`（退出极简/全屏后侧栏开关与进入前一致）。收起仍靠移出面板 / 点阅读区。
- **与全屏叠加**：极简中再进全屏，全屏布局（居中窄正文、滚动条钉视口、系统时钟）覆盖其上；退出全屏后仍留在极简。全屏中不可进出极简（须先退出全屏）。全屏下 `ESC` 在关完上层后须**连按两次**才退出（第一次顶部胶囊提示「再按 1 次 ESC 退出全屏」）。
- **章节导航**：与全屏一样移到底栏浮层，避免占阅读区底边。番茄钟进行中在角标显示（系统时钟仍仅全屏）。
- **持久化**：`isMinimalistView` 写入本窗口设置（主界面 `colorTxt.ui.settings`，找书 `colortxt.findBook.settings`），不跨窗口同步。找书阅读器同一套入口与 chrome。退出极简后侧栏回到文档流时会再居中当前章（与退出全屏相同）。

### 全屏正文宽度与两侧空白滚轮

- **设置块**：设置 → 阅读 → **「全屏阅读」**：含「全屏阅读区域宽度」与「全屏时在左下角显示系统时间」（`fullscreenShowSystemTime`，默认开启；`FullscreenSystemClock` 以 `h:mm` 显示于左下角，无底色，文字为 50% 透明度的 `--reader-body-text`）。
- **宽度**：设置里的「全屏阅读区域宽度」对应 `fullscreenReaderWidthPercent`，由 `useAppFullscreenReaderLayout` 的 `fullscreenReaderPaneStyle` 在全屏时给 `readerPaneWrap` 设 `width` / `maxWidth`（百分比）与水平 `auto` 外边距，使正文区在 `.layout` 内水平居中；两侧露出与正文同背景的空白。
- **滚轮**：
    - 空白区不在 Monaco 视图 DOM 上，原生 wheel 不会进入编辑器。
    - `App.vue` 在 **`.layout`** 上监听 **`@wheel`**，由 `useAppFullscreenReaderLayout.onLayoutWheel` 判断指针是否在 `readerPaneWrap` 矩形**之外**（左右空白）；且事件与全屏侧栏无关时，先尝试 **`tryHandleReadingRulerWheel`**（阅读尺开启则按滚动倍率移锚点），否则调用 `ReaderMain` 的 **`delegateEditorWheelFromBrowserEvent(ev)`**。
    - 内部对编辑器实例调用 **`delegateScrollFromMouseWheelEvent`**（`CodeEditorWidget` 运行时方法，未写入 `monaco` 的 `.d.ts`），与正文内滚轮走**同一条** Monaco 滚动逻辑。
- **`preventDefault` 顺序**：Monaco 在 `_onMouseWheel` 开头若发现 **`ev.defaultPrevented` 已为 true 会直接 return**，故 **`delegateEditorWheelFromBrowserEvent` 须在 `preventDefault` 之前调用**；委托完成后再对布局层 `preventDefault()`。侧栏内滚动通过 `composedPath` / `elementFromPoint` 与 Shadow DOM 向上判定排除，避免误劫持。
- **点击**：可选模式下点击左右空白仅聚焦阅读器。**点击模式**下与正文区相同：松开左键下一屏、松开右键上一屏；按下后拖动可滚动正文（视口右缘滚动条带除外）。**阅读尺开启时**左右键按「聚焦行数」移动阅读尺锚点，滚轮按滚动倍率移动锚点。
- **其它滚动**：键盘方向键、PageUp/PageDown 等仍由 `ReaderMain` 的 **`scrollByDeltaY` / `scrollByLineStep` / `scrollByPageStep`** 等驱动，与上述空白区 wheel 委托无关。翻页重叠完整行见 **「黏性章节条」**。
- **样式**：全屏时 Monaco 纵向滚动条、概览尺、**小地图**（编辑态开启时）通过 `appShell.css` 固定到视口最右侧：滚动条/概览尺 `right: 0`，小地图 `right: var(--txtr-fullscreen-scrollbar-size)`（默认 14px，与 Monaco 默认竖条宽度一致）；须 **`left: auto`** 覆盖 Monaco 内联 `left`，避免小地图落在居中正文中间。与窄正文居中并存。
- **竖条显隐**：Monaco 竖条始终 `visible`。全屏 / 极简**只读**下与系统光标同步：光标因静止隐藏时竖条与概览尺一并淡出（`.fullscreen--cursorHidden`），鼠标一动即出现。**编辑模式**光标与竖条均常显，不空闲隐藏。拖动滑块时即使光标已藏也保持竖条。概览尺左边线（滚动条左侧细线）窗口 / 极简 / 全屏都绘制。主窗与找书阅读器相同。
- **滚动条轨道行为**（**`scrollbarTrackBehavior`**：`disabled` | `page` | `jump`，设置 → 阅读 → **滚动**，默认 **`page` / 翻页**；旧布尔键 **`disableScrollbarTrackJump`** 读盘时迁移为禁用/跳转）：仅**只读**生效；**编辑模式**与 **智能排版 Diff 预览**始终为跳转。实现见 **`monaco/scrollbarTrackJumpGuard.ts`**（`editorHost` 捕获轨道 `pointerdown`）。
  - **禁用**：拦截轨道点击（滑块仍可拖）。
  - **翻页**：点滑块上方/下方分别走 **`scrollByPageStep(-1|1)`**，与空格 / PageUp·Down / 点击模式翻页同一套（粘性条重叠完整视觉行；阅读尺开启时移锚点）。
  - **跳转**：放行 Monaco 默认按点击位置比例跳转。
  - 概览尺为 `pointer-events: none`，点击落在下方轨道上，同受此设置约束。

## 阅读器字号、行间距、字间距与段间距

实现集中在 `src/renderer/src/constants/appUi.ts` 与 `src/renderer/src/monaco/readerEditorOptions.ts`（`readerEditorLineHeight` / `letterSpacing`）；段间距另见 `src/renderer/src/monaco/lineSpacing.ts` 与 `electron.vite.config.ts` 对 Monaco `LinesLayout` 的 transform。

- **字体**：顶栏 `FontPicker` 即时预览；设置 → 阅读最上方同一套弹出菜单，选字体只改草稿，点「确定」后写入阅读器。钉选系统字体即时持久化，不等确定。
- **系统字体面板**（`FontPicker` →「系统字体」）：
  - 标题旁 **刷新**（至少转约 400ms）强制重枚举；过滤输入与右侧 **`AppCustomSelect`** 合为一组（类似 append）：**字体族**（默认，每族一行、不加字重后缀）/ **区分字重**（同族拆成常规、细体、粗体等，名称带中文后缀）。列表模式写入 **`colorTxt.ui.fontPickerDistinguishWeights`**（`"1"` = 区分字重）；「设置 → 阅读 → 重置当前页」会清回「字体族」并派发 **`colortxt:font-picker-list-mode-reset`**。
  - **列表预览**用真实系统族名 + `font-weight` + `font-style`（`previewFamily` / `previewWeight` / `previewItalic`，即时、不走别名 CSS）；**选中**多字重项时才用别名 `cssFamily` + `@font-face`（优先 `colortxt-local://` 的 `url()`，辅以 `local()`）锁文件，避免只按族名落到错误字重。斜体行预览为斜体，粗斜体同时加粗并倾斜。
  - Windows 主进程以 WPF/`GlyphTypeface` 为主，再用 **`font-list`** 补 GDI 常漏的中文族（方正、华康等）；`file://` 映射为 **`colortxt-local`** 供渲染进程加载。
  - **启动不扫全量字体**：入口只跑 **`bootstrapSystemFontFacePins`**，从 **`colorTxt.ui.systemFontFacePins`** 恢复已选字重别名的 `@font-face`（有绝对路径则 IPC **`fonts:registerFontFilePaths`** 重注册）；打开「系统字体」或点刷新才 **`ensureSystemFontCatalog`** 全量枚举。选中别名或生成目录时写入 pin 缓存。磁盘上字体已删时注册失败，阅读器回退系统默认字形，一般不崩。
- **字号**：`minFontSize`～`maxFontSize`（整数 px），顶栏加减、快捷键与设置面板滑块共用同一状态。顶栏「减小字号 / 加大字号」按钮 `title` 为「加大字号 (Ctrl+=)：24 → 25」形式（有绑定时快捷键跟在操作名后；当前值 → 点击后的值；已到上下限时只显示当前值）。快捷键或顶栏加减时阅读区正中胶囊显示 **`字号：20`**。其它带快捷键的顶栏/侧栏图标按钮在 `title` 后附「 (快捷键)」（`shortcutUtils.titleWithShortcut`）。
- **行间距倍数（UI「行间距」，`lineHeightMultiple`）**：最小为 `minLineHeightMultiple`，步进 `lineHeightMultipleStep`（如 0.1）。对应 Monaco `lineHeight`。顶栏「减小行间距 / 加大行间距」按钮 `title` 同口径（一位小数，如「加大行间距 (Ctrl+]）：1.5 → 1.6」）。快捷键或顶栏加减时阅读区正中胶囊显示 **`行间距：1.5`**。
- **上限随字号变化**：Monaco 将编辑器 `lineHeight` 限制在约 `monacoMaxLineHeightPx`（150）像素量级；应用内像素行高由 `readerEditorLineHeight(字号, 倍数)` 得到（`Math.max(1, Math.round(字号 × 倍数))`）。
- **夹紧与持久化**：`maxLineHeightMultipleForFontSize(字号)` 得到该字号下允许的倍数上限；加载与设置「确定」时用 `clampLineHeightMultipleForFontSize` 将倍数夹到合法区间。
- **字间距（`letterSpacingPx`）**：默认 `0`，范围 `-5`～`20`（px，步进 0.5），对应 Monaco `letterSpacing`。默认快捷键 **减小** `Ctrl+Shift+[` / **加大** `Ctrl+Shift+]`（Mac 为 `Command+Shift+[` / `]`）。快捷键调节时阅读区正中弹出胶囊（与全屏 `fullscreenTip` 同外观）显示 **`字间距：X`**（约 1 秒后淡出；连按重置计时）。
- **段间距（`lineSpacingPx`）**：默认 `0`（关闭），范围 `0`～`100`（px）。加在每个**物理行**（Monaco model line）最后一条 view 行之后；软换行中间不加距。与「压缩空行时保留一个空行」并存（前者为布局，后者为文本管线）。实现上经 Vite transform 改写 Monaco **`LinesLayout`**：行偏移 / 视口累加 / **`getVerticalOffsetForWhitespaceIndex`**（插图 ViewZone 的绝对 `top`）均计入段间距；若只改行高未改 whitespace 偏移，md 插图会叠在上方正文上。独占行插图会删掉物理行，故另在 ViewZone 高度底部计入同一 **`lineSpacingPx`**（见 **`syncReaderImageViewZonesLineSpacing`**）。默认快捷键 **减小** `Ctrl+;` / **加大** `Ctrl+'`（Mac 为 `Command+;` / `'`）；胶囊 **`段间距：X`**。
- **选区圆角**：阅读器 **`roundedSelection: false`**。Monaco 默认圆角会在列重叠的多行选区内角铺 `.cslr` 再用编辑器底色抠图；阅读器底色透明以透出背景图，铺实心 **`--reader-bg`** 会露出色块，故关掉圆角。
- **章节标题上下保留空行（`chapterTitleBlankMode`）**：默认 `before2After1`（上面 2 空行，下面 1 空行）。仅在开启「压缩空行」时生效；可选 `before1`（上 1）、`before1After1`（上 1 下 1）。若开了「保留一个空行」，非标题正文行下方仍会保留一行空行。
- **左右边距（`readerHorizontalInsetPx`）**：默认 `0`，范围 `0`～`160`（px）。通过给阅读器 `editorShell` 左右 padding 收窄 Monaco 宿主实现；换行随 `automaticLayout` 变窄。实际单侧边距为 `min(设定值, floor((窗格宽 − minReaderBodyWidthWithHorizontalInsetPx) / 2))`，正文宿主宽度不低于与 `SIDEBAR_MIN_READER_WIDTH` 相同的 **300px**。窗口模式下竖条/概览尺/小地图 CSS 钉到阅读窗格右缘；全屏下钉到视口右侧。左右留白上的滚轮/点击与全屏外侧空白相同，委托给正文滚动与聚焦。默认快捷键 **减小** `Ctrl+Shift+,` / **加大** `Ctrl+Shift+.`（Mac 为 `Command+Shift+,` / `.`，避免与系统 **`Command+,` 打开设置**冲突）；胶囊 **`左右边距：X`**。**智能排版 Diff 预览**期间不套用该边距（对照区铺满阅读窗格）。
- **设置面板**：最上方为字体弹出菜单；字号、行间距、字间距、段间距、左右边距均为滑块；行间距滑块的上限随草稿字号变化；拖动字号若导致当前行间距超限时，会自动下调行间距草稿。**Markdown** 配置块（在「阅读尺」上方）含「插图高度」滑块（默认 100，范围 50–1000，步进 50）。
- **仅加大字号**（快捷键 / 顶栏）：若当前行间距倍数在新字号下超限，会自动下调倍数并写回阅读器与持久化。

## 定时滚动

自 **2.8** 起支持按固定间隔自动向下滚动正文，便于解放双手阅读。

### 功能与入口

| 项目 | 说明 |
| ---- | ---- |
| 顶栏 | **`AppHeader`**：**语音朗读** 左侧 **定时滚动** 按钮（`play.svg`）；开启后按钮为激活态 |
| 设置 | **设置 → 阅读 → 定时滚动**：**范围**（**一屏** / **一行**，**`RadioGroup`**）、**间隔（毫秒）**（**`NumericInput`**，默认 3000，夹紧 200～600000） |
| 滚动实现 | **`useAppTimedScroll`** 以 `setInterval` 驱动；**一屏** → **`ReaderMain.scrollByPageStep(1)`**（阅读尺开启时按「聚焦行数」移锚点），**一行** → **`scrollByLineStep(1)`**（阅读尺开启时锚点下移一行） |
| 持久化 | **`colorTxt.ui.settings.timedScroll`**（`{ range, intervalMs }`）；常量与 merge 见 **`constants/timedScroll.ts`**、`cacheStore.ts`；设置 **确定** 后写入；运行中修改间隔、或**任意阅读区滚动/跳转**（滚轮、快捷键、点击模式、侧栏跳转、章节导航、定时滚动自身等，经 `probeLineChange` 的 `fromAnyScroll`）会从当前时刻重新计满间隔 |

### 开启 / 停止条件

- **可开启**：已打开文件、非 `loading`、非编辑模式、非朗读中、视口未到底、模型行数 &gt; 0。
- **自动停止**：滚到文末（**`viewportAtBottom`**）、切换文件、进入编辑模式、开始加载、开启语音朗读。
- **互斥**：与 **语音朗读** 不能同时运行（顶栏互禁 + `useAppTimedScroll` / `onVoiceReadToggle` 双向防护）。

## 阅读尺（聚焦行淡化）

适合注意力不容易集中时阅读：聚焦带内视觉行正常显示，其余行半透明（改 `.view-line` 透明度，不盖背景图）。主窗与找书阅读器共用设置。

- **入口**：顶栏「编辑模式」与「点击/可选模式」之间的 **阅读尺** 按钮（`reading_ruler.svg`）；**编辑模式下不显示、不淡化**。**语音朗读进行中（含暂停）** 顶栏按钮禁用、不淡化、不移尺（不改设置；停止朗读后若仍开启则按视口中间行重新采锚）。设置 → 阅读 → **「阅读尺」** 可开关并配置。
- **持久化**（`colorTxt.ui.settings`，默认关）：**`readingRulerEnabled`**、**`readingRulerFocusLines`**（1–10，默认 1）、**`readingRulerDimOpacity`**（0–1，步进 0.05，默认 0.2）、**`readingRulerTransitionEnabled`**（焦点行过渡动画，默认开）、**`readingRulerDimStickyTitle`**（淡化粘性章节标题，默认开）。
- **聚焦带**：锚点钉在聚焦带**中间**那条有内容的视觉折行上（软换行按折行计），按 N 向两侧扩散（先下后上；奇数恰好居中，偶数多出的行在下方）。中间的空行不计入、保持淡化。改「聚焦阅读行数」时中间行不变。不是 Monaco 光标行，也不是语音朗读当前行。设置 → 阅读 → **「过渡动画」**（**`readingRulerTransitionEnabled`**，默认开）：焦点行切换时约 0.2s 淡入；再叠加 **平滑滚动** 时离开的行同时淡出。关闭过渡或系统「减少动态效果」时无动画。
- **启用**：打开阅读尺时，当前视口（扣粘性章节条）垂直方向的**中间视觉行**作为聚焦带**中间行**（奇数恰好居中，偶数多出的行在下方），不额外滚动。打开窗口并**恢复阅读进度**后同样按当时视口中间行重新采锚。
- **选区**：选区覆盖到的视觉行全部不淡化（例如 N=2 但选了 5 行，这 5 行都清晰）；取消选区后回到锚点那条带。
- **鼠标**：阅读操作一律移动**锚点**（聚焦带由锚点按 N 向两侧渲染）；左右键因模式而异。
  - **可选模式**：左键可拖选文本（不改锚点），右键出菜单。
  - **点击模式**：左键/右键翻页（按「聚焦行数」移动锚点）；按下拖动仍滚视口，滚动过程中把视口中间行设为锚点。
- **方向键**：锚点沿有内容的视觉行移动 **1** 行（空行不计入），并把聚焦带滚到视口中央。
- **滚轮**：按设置「滚动倍率」移动锚点（一次滚轮刻度 × 倍率 行，默认 1 格 1 行；按住 Alt 再乘「滚动加速倍率」）。查找栏 / 滚动条 / 小地图上的滚轮仍滚视口，滚动过程中跟视口中间行。聚焦带已贴边时，找书再滚即切章（与翻页相同）。
- **翻页**（空格、`PageUp` / `PageDown`、点击模式左右键、定时滚动「一屏」）：锚点移动 **聚焦行数**（相邻聚焦带不重叠）。定时滚动「一行」与方向键相同。聚焦带已经盖住文首/文末的有内容行时，不再沿该方向移锚点；找书则切章。
- **跳转 / 切章**：侧栏搜索·书签、书钉、查找栏、高亮词 / 笔记 / AI 跳转、拖滚动条、小地图等先滚视口，滚动过程中把**视口中间视觉行**设为锚点（不把跳转目标行当成锚点）。贴文首/文末时聚焦带贴该侧（锚点取带的自然中间行）。切章时章节标题滚到视口中间并作为锚点。
- **快捷键**：「向上滚动 / 向下滚动」（默认 ↑ / ↓）即方向键移锚点。朗读滚动锁定期间仍拦截行滚与空格。
- **切章**：找书阅读器点目录 / 上一章 / 下一章 / 向下边界切章同上；**向上边界切章**仍落在章末，聚焦带贴文末。
- **插图**：块级插图 ViewZone 紧挨聚焦带的**视觉行**时保持清晰（软换行按折行计，不按物理行提前亮起）；淡化的插图鼠标悬停时也恢复清晰。
- **粘性章节标题**：设置 → 阅读 → **「淡化粘性章节标题」**（**`readingRulerDimStickyTitle`**，默认开）开启后，只淡化条内标题文字（条底仍不透明，避免正文透上来）。关闭则粘性条文字不淡化。

## 阅读器交互模式（可选 / 点击）

顶栏「编辑模式」右侧先是 **阅读尺**，再是 **可选模式 / 点击模式**（`select_mode.svg` / `click_mode.svg`）；二者均在**编辑模式下不显示**。持久化 **`readerClickMode`**（`colorTxt.ui.settings`，默认 **`false`** = 可选模式）；主窗与找书阅读器共用，按窗口独立内存（与字号等阅读 UI 相同）。

| 模式 | 行为 |
| ---- | ---- |
| **可选模式** | 当前默认：可选中文本，进行标记、记笔记、词典、翻译等 |
| **点击模式** | 只读正文不可选，鼠标为箭头（`cursor: default`，全屏静止后仍可被 `fullscreen--cursorHidden` 隐藏）；阅读区内及全屏左右空白 **松开左键** 下一屏（同 `PageDown` / `scrollByPageStep(1)`），**松开右键** 上一屏（同 `PageUp`，不打开正文右键菜单）。按下后拖动则按指针移动滚动正文（内容跟随指针），超过阈值后松开不再翻页。**已有选区时**，左/右键单击只取消选中，不翻页。**阅读尺开启时**翻页按「聚焦行数」移锚点；滚轮按滚动倍率移锚点 |

- **不生效**：编辑模式、语音朗读锁滚动、智能排版 Diff 预览。查找栏、滚动条、小地图上的点击仍走原交互。电子书内链与插图灯箱仍优先于翻页。**顶栏字体/转换/更多等弹层打开时**，点阅读器先关弹层：当次单击不翻页，拖动仍可滚动正文（不进入选区）。**窗口失焦后**点阅读区只让窗口重新获得焦点，当次不翻页（拖动仍可滚动）。
- **按住 Alt**：临时切换另一种模式（不改保存的偏好）；顶栏按钮换成对应图标，且图标为 **warning** 色。松开 Alt、失焦、打开模态层后恢复。编辑模式或焦点在阅读器以外的输入框时不启用。**左键已按下后再按 Alt 不切模式**，只读 Monaco 使用 `multiCursorModifier: ctrlCmd`，此时 Alt 拖选为列选。先按 Alt 再拖：从点击模式临时切到可选时抹掉事件上的 `altKey`，为普通连续选区。
- **找书**：点击翻页走同一套 `scrollByPageStep`；已在章节边界时经 **`interceptReadonlyPageStep`** 与空格 / `PageDown` 一样切章（见 [书源找书.md](./书源找书.md) → **§6.7**）。**阅读尺开启时**尺无法再沿该方向移动即视为边界（方向键 / 滚轮 / 翻页相同）。

## 番茄时钟

设置 → 阅读 → **「番茄时钟」**（`pomodoro` / `PomodoroSettings`，默认启用）：阅读时长 25 分钟、短休息 5 分钟、长休息 15 分钟。启用后底栏最左侧显示启动按钮（`icons.history`）；运行中为饼图倒计时，点击饼图可在「仅饼图」与「饼图 + `m:ss` + 暂停/继续 + 停止」间切换。阅读时长结束时全窗毛玻璃遮罩（`PomodoroBreakOverlay`）居中显示「休息一下」与休息倒计时；每完成 4 轮阅读进入长休息。实现见 `usePomodoroTimer.ts`。找书阅读器关闭时自动停止。

## 底栏（`AppFooter`）

由 **`AppFooter.vue`** 渲染，数据与事件由 **`App.vue`** 注入。阅读进度与百分比文案仍来自 **`useAppReadingProgress`**（与其余展示口径一致）。左侧可挂番茄时钟控件（`PomodoroFooterControl`）。自动暂停已开启且 **正在播放** 时，「阅读进度」左侧显示 **`语音朗读：…`**（章节剩余 `M/N` 或剩余时长）；暂停 / 停止后不显示。详见 [语音朗读](./语音朗读.md) → **「朗读设置」**。

### 左侧路径

- **展示**：`footerPathCaption` — 普通书籍为 **`physicalReaderPath ?? currentFile`**；**电子书转换中**为源书路径（`ebookConversionSourcePath`）。
- **交互**：路径为链式按钮，点击打开 **`AppContextMenu`**（非直接打开资源管理器）。
- **菜单项**（均受「整体在窗口内」夹取；某条不可用时仍显示为 **disabled**；有当前文件时导出/清除可用）：
  - **导出书包** / **导出书包（带阅读进度）**：见 **「彩读书包」**（`icons.export`）；菜单最上方，其下分隔线。
  - **清除阅读数据**（**danger**，`icons.clear`）：确认后调用 `clearReadingDataForPaths`（与设置「阅读数据」面板删除同语义），从 **`file.meta` 删除**当前会话路径的进度 / 书签 / 高亮 / 笔记 / 角色卡等（含 AI 对话 / 向量 / 分词与立绘目录），并移出最近打开；写盘不与磁盘旧 meta 合并。其下再分隔线。
  - **在文件管理器中显示**：与 **`revealCurrentFileInFolder`** 一致，目标路径为 **`physicalReaderPath ?? currentFile ?? ebookConversionSourcePath`**（无可用路径时 disabled）。
  - **重新加载**：**`openFilePath(currentFile, { keepSidebarTab: true })`**；无 **`currentFile`**、**`loading`** 或 **`ebookParsing`** 时为 disabled。
  - **重新转换**（仅源路径为电子书且当前会话已打开转换后的 `.md`）：**`openFilePath(..., { forceEbookConvert: true, keepSidebarTab: true })`**，忽略缓存、强制重跑 `convertBookBufferToArtifacts`；**`warning`** 样式菜单项。
  - **关闭文件**：**`closeCurrentFile`**（**danger** 样式）；无 **`currentFile`** 时 disabled。

### 右侧编码

- **展示**：当前探测/保存用编码标签（**`fileEncoding`**）；打开文件时由主进程 **`detectTextEncoding.ts`** 自动探测（流式读与编辑载入共用），标签经 `encodingLabelForFooter` 显示（如 `UTF-8`、`GB2312`、其它 chardet 名大写）。
- **可点条件**：由 **`footerEncodingActionsEnabled`** 控制（需 **`physicalReaderPath`**、**`currentFile`**、非 **`loading`**、非 **`ebookParsing`** 且 **`writeTextFile` 可用**）。
- **菜单**：**保存为 UTF-8** / **保存为 GB2312** → **`saveReaderBufferWithIpcEncoding`**：`ReaderMain.getAllText()` → **`writeTextFile(physicalReaderPath, text, 编码)`** 覆盖落盘；成功后更新 **`fileEncoding`**、**`readerSaveEncoding`**，并 **`markReaderEditSaved`** / 清除编辑脏标记（与顶栏保存路径一致）。

### 弹出定位与互斥

- **`AppContextMenu`** **`placement="aboveFooterMouseX"`**：以底栏 **`<footer>`** 的 **`getBoundingClientRect().top`** 为界，菜单**底边**始终在底栏之上（留缝）；**横向**以打开瞬间的 **`clientX`** 与菜单宽度居中对齐后再做视口夹取。
- **路径菜单与编码菜单互斥**：打开其一会先关闭另一；共享同一组指针/底栏顶边坐标（`footerPopoverFooterTopPx` / `footerPopoverPointerXPx`）。

## 彩读书包（导出 / 导入）

将**当前可读正文**与本书阅读数据打成 ZIP，便于迁移；**不**打包电子书原文件（epub/mobi 等）。实现：`utils/readerBookPack.ts`、`utils/readerBookPackImport.ts`；导出由底栏路径菜单触发；打开式导入走 **`openFilePath`**（打开对话框 / 非侧栏拖放）；侧栏「选择目录」与侧栏拖放走 **`importBookPacksIntoFileList`**（只入库不打开）。

### 包格式

- **建议文件名**：
  - 明文：`{书名}.ctz`（普通 ZIP；**ColorTxt Zip**），可用常见解压软件打开。
  - 加密：`{书名}.ctzx`（**CTZE** 封装的加密 ZIP；非标准 ZIP 密码，其它解压软件无法直接打开）。
- **系统关联**（安装包写入；便携 / 未集成桌面的 AppImage 可能无效）：
  - **`.ctz` / `.ctzx`**：注册为默认打开方式（Win/mac 安装包；Linux 为自定义 MIME `application/x-colortxt-book` / `application/x-colortxt-book-encrypted`），双击用彩读打开。
  - **`.txt` / `.md`**：只加入「打开方式」列表——Windows：`OpenWithProgids`；macOS：`LSHandlerRank = Alternate`；Linux：桌面项声明已有 MIME `text/plain` / `text/markdown`（不独占扩展）。
  - **Linux AppImage**：electron-builder 21+ 默认**不**自动做桌面集成；需用户用 AppImageLauncher 等集成，或自行安装 `.desktop` / MIME 后，上述声明才会进「打开方式」。
- **结构**：

```
manifest.json                 # kind: "readerBook", schemaVersion: 1
content/{basename}            # 可读正文（txt 或转换后的 md）
content/{imagesDirName}/**    # 可选：转换 md 旁的 .Images/ 整目录
bookmarks.json                # 可空则省略
highlights.json
notes.json
characters/manifest.json      # 复用角色卡包结构（kind: characterRoster）
characters/portraits/*.png
```

- **`manifest.json` 主要字段**：`contentFileName`；可选 `sourceEbookFileName`（导出会话为电子书时的源书 basename）、`imagesDirName`、`viewportTopPhysicalLine`（仅「带阅读进度」导出；**不**打包 `editorViewState` / 滚动百分比）。
- **正文**：始终取 **`physicalReaderPath`**；电子书只打包转换后的 `.md`，若旁路存在 **`.Images/`** 则一并打包。

### 导出

- 底栏路径菜单：**导出书包** / **导出书包（带阅读进度）** → `buildReaderBookPackZip` + `showSaveDialog`。
- 若「设置 → 常规」**书包默认密码**非空，导出前对 ZIP 整包加密（`sealBookPackZipIfNeeded`），默认文件名与保存过滤器为 **`.ctzx`**；否则为 **`.ctz`**。
- 带进度：阅读器视口顶行 → 物理行写入 manifest（编辑态即该行；否则 `viewportDisplayLineToPhysicalLine`）。
- meta / 立绘取自 **`currentFile`**（会话路径）上的 `file.meta` 与立绘缓存目录。

### 导入

- **入口（打开后阅读）**：顶栏「打开文件」（默认「电子书」过滤器含 `ctz`/`ctzx`；另有单独「彩读书包」过滤器）、非侧栏拖放、或系统关联双击 `.ctz`/`.ctzx`。成功后 **`openFilePath`** 打开解压/命中路径。
- **入口（侧栏只加列表）**：「选择目录」、「更多 → 选择文件」、侧栏拖放文件/目录。收集到的 `.ctz`/`.ctzx` 走 **`importBookPacksIntoFileList`**：**不**调用 `openFilePath`（除非命中**当前已打开**且带进度，见下）。`.ctz` 本身不进可读列表。
- **`parseReaderBookPackZip`**（含密码解密）校验 manifest / `kind`，合法才导入；打开入口失败则报错中止；侧栏批量则记失败/跳过并继续下一包。
- 加密包（通常为 `.ctzx`，亦可能误标为 `.ctz`）：
  - **打开单包**：优先设置 **`bookPackPassword`**；失败则弹密码框重试（取消中止；「显示密码」写入 `colorTxt.ui.bookPackPromptShowPassword`）。
  - **侧栏批量**：本次流程临时密码本，初始为设置密码（若有）；按序 `tryPasswords`，皆失败再弹框；成功解密的密码 **unshift** 到本顶。弹框另有「**解密失败时跳过**」（仅内存，不持久化）：勾选后再次解密失败则跳过**本包**；**取消**无论是否勾选都只跳过本包，整批继续。流程结束丢弃密码本。
- **解包蒙层**：**`bookPackUnpacking`** → `AppOverlays` 全屏「解包中…」（覆盖确认 / 密码框前临时关闭蒙层）。
- **同名匹配顺序**（命中即停）：
  1. **当前打开文件**（即使未在「文件」列表；电子书还可对 `physicalReaderPath` 的 md basename）。
  2. **「最近的文件」**（仍存在的同名，取最近一条）。
  3. **「文件」列表**（多个同名取列表中靠后一条）。
  4. 都没有 → 解压到 **`bookPackUnpackDir`（空则 `userData/UnpackedBooks`）/`{contentFileName}`**（及旁路 Images），加入文件列表（未分类），meta 挂新路径。
  - 命中 1～3 时：若目标路径尚不在「文件」列表，**补进列表**（避免仅因「最近打开」命中而导致侧栏加书包看不见书）。
- **电子书命中**：meta 仍挂**电子书绝对路径**；对比/覆盖对象为转换 md（及 Images），不改 epub 本体。
- **内容相同**：只合并更新书签 / 高亮 / 笔记 / 角色卡（及可选进度）；**不同**：确认后覆盖正文（及 Images）。解压目录下已有同名文件时同样：相同复用 / 不同确认覆盖，**不加数字后缀改名**。
- **进度**：有 `viewportTopPhysicalLine` 则写入 meta 并清除 `editorViewState`。侧栏批量**不**立刻打开：用户之后从文件列表首次打开时，靠「仅锚点」恢复链路滚到对应物理行（**无需**额外 `pendingRestore*` 持久字段）。若批量导入命中**当前已打开**同名书且带锚点，会补一次 `openFilePath(..., { restorePhysicalLine })` 以立刻看到进度。
- **进度落盘注意**（导入后未滚动即退出再启动）：
  - 书包**不**带 `editorViewState`；打开瞬间若用 live 顶部视口写 meta，会把导入锚点冲成第 1 行。
  - **`touchRecentFile`** 在 **`readingProgressSynced === false`** 时不捕获 live `editorViewState` / 视口；流结束恢复视口并置同步后补一次位置快照再门控写盘。
  - 重新打开 / 启动会话：若仅有有效 **`viewportTopPhysicalLine`**、无 `editorViewState`，仍按物理行恢复（与「同时有 viewState+锚点」的 Monaco 路径并列）。

## 只读展示管线（`reader/readerDisplayPipeline.ts`）

流式读盘阶段 **`useTxtStreamPipeline`** 只向 **`physicalLineContents`** 追加**物理行**（插图锚点删行会收缩映射表）。加载过程中**不**累加总字数、**不**跑章节匹配；流结束或切换「压缩空行 / 行首缩进 / 转换 / 文本替换」时调用 **`formatPhysicalLinesForReader`** 得到展示正文与 **`displayLineToPhysicalLine`** / **`chapterTitleDisplayLineByPhysical`**，再（若有启用规则）经 **`applyReplaceRulesToDisplayText`** 套用文本替换（见下），再（若已启用转换）**`applyTextDisplayConverts`**，然后 **`setFullText`**、更新 **`totalCharCount`**（展示正文 `length`）并触发章节重建。

- **`applyReaderDisplayFromPhysicalLines(physicalAnchorLine)`**：基于内存物理行重算展示层（格式化 → **文本替换** → 展示层转换）并恢复视口（`useAppReaderUiPrefs` 切换开关、`syncChaptersAfterViewportSettled`）；失败回滚 UI 开关。**`physicalLineContents` 始终保留磁盘原文**，替换与转换仅作用于写入 Monaco 的展示正文。
- **文本替换作用域**（对齐 Legado「作用于标题 / 作用于正文」；纯函数 **`@shared/bookSource/replaceRuleApply.ts`** 的 **`applyReplaceRulesToDisplayText`**）：**作用于正文**的规则套格式化后的**全文**；章节标题展示行（由 **`chapterTitleDisplayLineByPhysical`** 标定）再恢复为套正文前原文，并只套 **作用于标题** 的规则（避免正文规则改写标题行）。正文规则若改变行数则无法按行号恢复，退化为在正文替换后的标题行上再套标题规则。找书阅读器仍分路径：标题走 **`applyTitleReplaceWithRules`**、正文走 **`applyContentReplaceWithRules`**（见 [书源找书.md](./书源找书.md) → **「文本替换」**）。
- **`physicalSearchRangeToDisplayColumns`**：侧栏搜索命中列 → Monaco 列；只读且 **`leadIndentFullWidth`** 时经 **`readerAnnotations.physicalColumnToDisplayColumn`**（章节标题行豁免，与标注装饰列映射一致）；**`readerEditMode`** 为 true 时列 1:1。
- **`syncMirrorFromReaderModel`**：编辑态将 Monaco 全文写回物理行镜像，供 **`runSidebarSearch`** 与底栏 **`totalCharCount`**（`getAllText().length`）使用。

## 简繁与全半角转换（顶栏「转换」）

自 **2.6** 起顶栏在「压缩空行」之前提供 **「转换」** 菜单（**`ConvertMenu.vue`**），分三类子菜单：**简繁**、**字母**、**数字**。菜单项与 OpenCC 配置映射集中在 **`@shared/textConvertTypes.ts`**；字母/数字全半角逻辑在 **`@shared/textWidthConvert.ts`**（仅 **`A–Z`/`a–z`** 与 **`0–9`**）。主菜单相对按钮水平居中；子菜单 flyout 按视口空间优先向右展开（见组件表 **`ConvertMenu.vue`**）。

### 阅读模式（展示层）

- **持久化**：**`textConvertZh`**、**`textConvertLetter`**、**`textConvertDigit`** 写入 **`colorTxt.ui.settings`**（默认均为 **`off`**）；顶栏/侧栏偏好变更时经 **`useAppPersistence`** 即时落盘。
- **加载管线**：流式读盘**不**在 chunk 阶段转换；**`onStreamEnd` → `flushCarry` → `applyReaderDisplayFromPhysicalLines`** 顺序为：**物理行 → `formatPhysicalLinesForReader` →（启用时）`applyReplaceRulesToDisplayText`（正文 / 标题分作用域）→ `applyTextDisplayConverts` → `setFullText`**。替换与转换均作用于**格式化后的展示正文**，不改变 **`physicalLineContents`**（磁盘原文缓存）。主窗口规则存 **`localStorage` `colortxt:replaceRules:app`**（找书为 **`colortxt:replaceRules:findBook`**）；顶栏「文本替换」打开 **`ReplaceRulePanel`**（`bucket=app`）。主窗口启用规则按当前打开文件的**书名**（去掉常见后缀）匹配 **替换范围 / 排除范围**（空范围=全部；建议下拉仅「当前书名」，无打开文件时不展示建议；匹配为范围**包含**书名，可选建议时追加到末尾（已有内容加 `，`）以便拼多本）。侧栏章节：`.txt` 从展示正文匹配；`.md` 物理行定结构；只读**标题取已去 `#` 的展示行**（「作用于标题」生效），编辑态经 ATX 解析取纯标题（侧栏不带 `#`）。
- **动态切换**：**`useAppReaderUiPrefs.setTextConvert*Read`** 更新设置后调用 **`applyReaderDisplayFromPhysicalLines`**，从 **`physicalLineContents`** 重新格式化并转换，**不重新读盘**；切换失败回滚设置。视口经 **`captureViewportRestoreAnchor`** 恢复。
- **简繁引擎**：渲染进程 **`services/textConvertApply.ts`** → preload **`convertTextOpenCc`** → 主进程 **`text-convert:opencc`** → **`textConvertOpenCc.ts`**（**`opencc`** 原生 **`convertSync`**）。澳门选项 **`mo2s`/`s2mo`** 映射为 OpenCC **`hk2s`/`s2hk`**。

### 编辑模式（改写缓冲区）

- **入口**：顶栏 **「格式化：转换」**（无 **「关」**）；**`App.vue`** → **`ReaderMain.applyEditFormatTextConvertZh/Letters/Digits`**。同模式另有 **「格式化：文本替换」**（打开 **`ReplaceRulePanel`**，主按钮「应用」= 保存规则 + **`applyEditFormatTextReplace`**）。

- **与智能排版 Diff**：预览期格式化行为见 [AI功能.md](./AI功能.md) → **「AI 智能排版」**。

## 阅读器编辑模式（正文磁盘编辑）

只读模式下正文由上述**只读展示管线**写入 Monaco。**编辑模式**下 `ReaderMain` 展示 **`physicalReaderPath` 磁盘全文**：Monaco 行与源文件物理行**一一对应**（不经压缩/缩进展示层）；保存时将 Monaco 全文按编码写回该路径。顶栏编辑菜单可对全文做**格式化**（`reader/readerTextFormat.ts`）：**压缩空行**、**行首全角缩进**、**简繁/字母/数字转换**、**文本替换**（见 **「简繁与全半角转换」** / **文本替换**），经 `ReaderMain.applyEditFormat*` 写回模型并 **`runEditFormatWithChapterSync`** 刷新章节。**AI 智能排版**（需启用 AI 阅读助手）详见 [AI功能.md](./AI功能.md) → **「AI 智能排版」**。

### 状态与入口（`App.vue`）

- **`readerEditMode` / `readerEditorDirty`**：是否处于编辑态、缓冲区是否与上次载入/保存快照不一致；`useAppShellThemeWatch` 在标题上对 dirty 追加 `*`。
- **`canEnterReaderEditMode`**：已打开文件、非 `loading`、**`readingProgressSynced`**、非 `ebookParsing`；否则顶栏「编辑」仅 **`appToast`**。
- **顶栏 `AppHeader`**：编辑开关、只读时 **可选/点击交互模式**、编辑态**保存**、编辑态**格式化**（压缩空行 / 行首缩进 / 转换 / 文本替换）；只读专用的压缩/缩进/转换/替换开关在编辑态由格式化菜单承担。
- **设置 → 编辑**：**`readerEditShowLineNumbers`**（默认关）、**`readerEditMinimap`**（默认关）、**`editAutoRefreshChapterList`**（默认开）；经 **`buildReaderMonacoModeEditorOptions`** 控制行号栏与小地图；小地图节标题由 **`buildChapterMinimapSectionHeaderDecorations`** 与章节快照同步。当前行背景：**`renderLineHighlight: "none"`**（只读/编辑相同）。**当前词**：**`occurrencesHighlight: "off"`**（只读/编辑相同；无空格中文会被当成整段词铺灰底）。**选区出现次数**：只读 **`selectionHighlight: false`**，编辑 **`true`**（选中「杨过」时其它「杨过」浅底高亮）。书源字段编辑器仍用默认词高亮。
- **只读禁止输入法合成**：Monaco 0.55 默认 **`editContext: true`**（Chromium EditContext）。只读改为 **`false`**（**`buildReaderEditorReadOnlyInteractionOptions`**），避免输入法在光标处画出空白合成框，并把视口滚回光标（`updateSelectionBounds`）。查找栏有独立 input，不受影响。**`installReaderReadOnlyImeGuard`** 再拦截只读下的 `compositionstart` / `beforeinput` / IME 键（焦点在 **`.find-widget`** 时放行）。编辑态仍开 EditContext；IME 层去掉全局 `textarea` 边框，并藏掉原生 caret（只留 Monaco 光标）。
- **底栏「编码」**：只读或编辑态均可将 **`getAllText()`** 按所选编码写回 **`physicalReaderPath`**。
- **切回只读**：未保存时 **`readerEditDiscardUnsavedMessageBox`** 确认后 `openFilePath` 重载；**`restorePhysicalLine`** 使用编辑态 Monaco 行号（即物理行），**不可**对编辑行号再调 `viewportDisplayLineToPhysicalLine`。
- **快捷键**：编辑态下滚动/翻页/查找等阅读快捷键仍由外层处理；Monaco 内仅保留编辑相关命令（如 **`colortxt.readerEdit.save`** → **`onSaveReaderFile`**）。
- **正文右键**（`AppContextMenu`，Monaco `contextmenu: false`）：**只读**为 **复制**（无选区时禁用）/ **选中本章**（按右键落点或选区起点落入的章节，选中该章标题行至下一章前；无选区也可用；无章节时禁用；找书阅读器 **`showSelectChapterMenuItem=false`** 不展示，因按章渲染）/ **全选** / **网络搜索**（`icons.browser`，无选区时禁用；子菜单为已配置引擎 +「搜索管理」；见 **「网络搜索」**）/ **编辑选中文本**（`icons.edit`，无选区禁用；选区物理原文超过 `maxPartialEditSelectionChars`（1000）时 **`appAlert`** 提示过大；`textarea` 弹窗改写物理片段并写盘/章节缓存后刷新展示；主界面与找书阅读器均支持；默认快捷键 **`Ctrl+E` / `Command+E`**）；**编辑态**为剪切 / 复制 / 粘贴 / **选中本章**（找书同上隐藏）/ **全选** / **网络搜索** /（可用时的 **AI 智能排版：选中文本**）。智能排版 Diff 预览期另有侧栏菜单，不走此项。**点击模式**下右键改为上一屏，不打开此菜单。进入/退出编辑模式默认快捷键 **`Ctrl+/` / `Command+/`**（`toggleReaderEdit`）。

### `ReaderMain.vue` 载入与滚动

- **载入**：`readWholeTextFile` → `setValue` → **`applyReaderMonacoModeOptions(true)`**；成功 **`readerEditLoaded`**（`encoding`）、**`readerEditDirtyChange(false)`**；`App.vue` **`onReaderEditLoaded`** 内 **`resyncMirrorFromReader`**、有搜索词则 **`scheduleSidebarSearch`**、**`refreshChapterListFromReader`**，并在 `finally` 解除 **`suppressChapterListAutoScroll`**。
- **进入/退出编辑前**：**`captureViewportRestoreAnchor`**（`reader/readerViewportAnchor.ts`：物理行 + 折行内视觉行下标；采样带为视口顶沿下约第 2 条字高）写入 **`readerEditRestoreAnchor`**，须在 `readerEditMode` 切换前捕获；恢复时 **`restoreViewportToRestoreAnchor`**。只读侧仍可用 **`captureViewportAnchorPhysicalLine`** 作回退。
- **脏检测**：`onDidChangeContent` → **`readerEditContentChange`**；`App.vue` **`onReaderEditContentChange`** 同步镜像，编辑态且有关键词时 **`scheduleSidebarSearch`**（行内改动即时重搜，不依赖 `totalLineCount` watch）。
- **压缩空行开启时进入编辑**：用捕获的物理行在 `setValue` 后 **`scrollLineToBottom` / `jumpToLine`** 对齐视口。

### 章节、书签与搜索联动

- 编辑载入/格式化后从全文重算章节（`.md` 用 **`buildChaptersFromMarkdownEditorText`**）；编辑态一般不挂章节标题**行内**装饰（避免改标题时 Monaco 渲染异常），小地图节标题见上。
- **`App.vue`**：**`scheduleChapterListRefreshFromEdit`**（`CHAPTER_REFRESH_DEBOUNCE_MS` ≈ 400ms）在 **`editAutoRefreshChapterList`** 开启且行数 ≤ **`editAutoRefreshChapterListMaxLines`**（30 万）时，于 **`onReaderEditContentChange`** 防抖刷新章节；否则 **`showEditChapterRefreshButton`** 为 true，由侧栏 **「刷新章节」** 手动触发 **`refreshChapterListFromReader`**。
- **书签**：编辑态存 **Monaco 行**；只读滤空时存**物理行**（见 **「书签」**）。
- **侧栏搜索**：详见 **「侧栏全文搜索」**；退出编辑时 **`watch(readerEditMode)`**（`false`）重搜；进入编辑不在此 watch 中搜，等 **`readerEditLoaded`**。

- **`file:readWholeTextFile` / `file:writeTextFile`**：见 `ipcHandlers.ts`；读盘编码与 **`file:stream`** 相同（**`detectTextEncoding.ts`**）；preload 暴露 **`readWholeTextFile`**、**`writeTextFile`**。

## 侧栏全文搜索（`useAppSidebarSearch` + `SearchPanel.vue`）

- 实现集中在 **`composables/useAppSidebarSearch.ts`**（由 `App.vue` 编排接线）；UI 为 **`SearchPanel.vue`**。
- **快捷键**：**`openSidebarSearch`**（默认 **`Ctrl+Shift+F` / `Command+Shift+F`**）打开侧栏「搜索」并聚焦输入框；阅读器有选区时填入选中文本并搜索。另有 **`openSidebarFiles`**（默认 **`Ctrl+Shift+E`**）、**`openSidebarChapters`**（默认 **`Ctrl+Shift+C`**）、**`openSidebarAiAssistant`**（默认 **`Ctrl+Shift+A`**）切到对应活动栏并展开侧栏（AI 功能关闭时 AI 项无操作）。极简 / 全屏下会同时展开浮动侧栏，并钉住直到指针进入侧栏（或点阅读区收起）。找书窗口无此侧栏，快捷键面板不展示这些项。
- **`runSidebarSearch`**：**只读**在 **`getDisplayLineContent`**（Monaco 展示正文，含压缩/缩进/转换）上逐**展示行**匹配；**编辑态**在 **`getPhysicalLineContent`**（与 Monaco 一一对应）上逐物理行匹配。同一行内每个 **`range` 一条结果**（对齐 VS Code）；`SidebarSearchResult` 含 **`displayLine`**、**`physicalLine`**、单段 **`range`** 与匹配用 **`text`**。
- **列表行号**：**`SearchPanel`** 展示 **`displayLine`**（只读=展示行，编辑=Monaco 行）；**`activeSearchResult`** 以 **`displayLine` + `rangeStart`** 标识当前项。
- **更多 → 复制**：剪贴板格式为 `路径` / `搜索` / `结果`（结果行仅内容）；**复制（带行列号）** 结果行为 `{physicalLine},{physicalStartColumn}: {内容}`（行号为物理行；列号编辑态即命中列，只读态经行首缩进映射推回；简繁/替换开启时列号可能与原文错位。内容与列表预览同为 trim 后文案）。
- **跳转**：**`onJumpToSearchResult`** → **`physicalSearchRangeToDisplayColumns`**（只读+行首缩进）或编辑态物理列 → **`revealRangeInCenter`** / 查找高亮。高亮词「下一处」与查找栏下一处/上一处：若光标不在视口内，先 **`ensureSearchAnchorCursorInViewport`** 挪到视口首行再搜。高亮词跳转用 **`findNextMatch`**；装饰条数上限 **19999**（与 Monaco 查找栏一致；默认 `findMatches` 仅 999，组词易超限导致后文无背景且回绕文首）。
- **重搜时机**：
  - **`watch(searchQuery)`**、匹配选项变化：始终防抖重搜。
  - **`watch(totalLineCount)`**：仅只读（加载完成、切换展示层导致行数变）；编辑态由 **`onReaderEditContentChange`** 负责。
  - **`watch(readerEditMode)`**：仅**退出**编辑（`false`）时重搜；**进入**编辑在 **`onReaderEditLoaded`** 之后重搜。

## Monaco 查找栏

ColorTxt 使用 Monaco 内建 **`actions.find`** / **`FindController`**（**`ReaderMain.toggleFindWidget`**）。查找栏 DOM 类名为 **`.find-widget`**；查找/替换输入框由 **`ContextScopedFindInput`** / **`HistoryInputBox`** 提供搜索历史（Monaco **`history.showPrevious` / `history.showNext`**，默认绑定 **↑ / ↓**）。

### Tooltip 方向（`postinstall` 补丁）

Monaco **0.55+** 移除了 VS Code [#272244](https://github.com/microsoft/vscode/pull/272244) 之前 **`HoverStyle.Pointer` 默认 `BELOW`** 的行为；未补丁时，查找栏按钮与输入框 placeholder tooltip 会默认在控件**上方**弹出，易被顶栏或阅读区 **`overflow: hidden`** 裁切。

**`scripts/patch-monaco-hover-pointer-below.mjs`** 在 **`npm install` → `postinstall`** 中与 **`electron-rebuild`**、**`patch-nested-sharp-stub.mjs`** 串联执行，幂等地修改 `node_modules/monaco-editor`：

| 文件 | 改动 |
| ---- | ---- |
| `esm/vs/platform/hover/browser/hoverWidget.js` | **`HoverStyle.Pointer`** 恢复 **`hoverPosition: BELOW`** 且 **`forcePosition: true`**（查找栏**按钮** tooltip 带小三角、固定向下） |
| `esm/vs/base/browser/ui/inputbox/inputBox.js` | **`InputBox.setTooltip`** 改为 **`setupDelayedHover` + `HoverStyle.Pointer`**（查找/**替换**输入框「查找 / 使用 ↑↓ 查看历史记录」类 tooltip 与按钮一致） |

升级 **`monaco-editor`** 后若 upstream 结构变化，脚本会在控制台 **`warn`** 并跳过，需对照 needle 手工调整。修改 `node_modules` 后须 **重启 dev**（必要时清 Vite 缓存）方可生效；亦可手动执行 **`node scripts/patch-monaco-hover-pointer-below.mjs`**。

**说明**：脚注悬停、补全框等仍走 **`overflowWidgetsDomNode`**（**`ReaderMain.ensureReaderMonacoOverflowHost`**）；查找栏 tooltip **不属于** overflow widget，不受 **`readerEditorOptions.fixedOverflowWidgets`** 影响。

### 快捷键与 ↑↓ 搜索历史

默认窗口快捷键 **`Up` / `Down`** 绑定 **`scrollUpLine` / `scrollDownLine`**。**`shortcutService.bindAppShortcuts`** 在 **`window` 捕获阶段**匹配并 **`preventDefault`**；**只读模式**下若焦点不在「应让出的 Monaco 区域」，↑↓ 会被当作滚行，Monaco 的 **`history.showPrevious` / `history.showNext`** 拿不到按键。

**`useAppWindowBindings`** 在 **`shouldDeferAction`** 中补充：**`keyboardTargetInsideFindWidget`**（**`ev.target.closest('.find-widget')`**）且动作为滚行时 **不拦截**，交给 Monaco 处理查找/替换输入框历史。**编辑模式**下焦点在 Monaco 内（含查找栏）时，滚屏/翻页/查找等仍经 **`EDIT_MODE_MONACO_DEFERRED_ACTIONS`** 整体让出（原有逻辑）。

### 与其它 UI 的协作

- **全屏顶栏**：查找栏展开时 **`updateFullscreenHeaderHover`** 内 **`isFindWidgetRevealed()`** 为真会强制收起顶栏（见 **「全屏阅读器 UI」**）。
- **标注工具条**：**`.find-widget`** 内点击/拖选不弹出选区工具条（**`useReaderAnnotations.isFindWidgetTarget`**）。
- **样式**：**`readerMainMonaco.css`** 覆盖查找栏计数/按钮 **`user-select`** 等；tooltip 本身由 Monaco **`.workbench-hover`** 渲染。

## 书签（行号语义、侧栏与弹窗）

### 持久化行号（`colorTxt.file.meta` → `FileBookmarkItem.line`）

- **只读**且经滤空管线时：存 **物理行**（与 `viewportTopPhysicalLine`、章节重建所用全文分行一致）。
- **`readerEditMode`**：Monaco 与磁盘一行对一行，存盘行号即 **Monaco 显示行**，不经 `viewportDisplayLineToPhysicalLine`。

### 添加书签时记哪一行

- **`ReaderMain.getBookmarkSaveAnchorDisplayLine()`**：与 **`jumpToBookmarkLine`** 对齐——在当前滚动下取视口内容区 **上沿 + 一行字高**（`scrollTop + EditorOption.lineHeight`）处的 **逻辑行号**，对 **`getTopForLineNumber`** 做二分（折行下不同于简单「顶行 +1」）；无编辑器/模型时返回 `null`。
- **`useAppBookmarkPins`**：`confirmAddBookmark` 与弹窗预览共用 **`getPendingBookmarkSaveLine()`**——新建时优先锚点显示行再映射为物理行（只读）或直接用显示行（编辑）；锚点不可用时回退 **`viewportTopPhysicalLine`**。**编辑已有书签** 时 **`editingBookmarkLine`** 始终为打开弹窗时的 meta 行键；点「更新为当前行」只写入 **`stagedEditingBookmarkLine`**，预览与 **`getPendingBookmarkSaveLine()`** 用 **`staged ?? editing`**；**「保存」** 时若行有变则 **`removeBookmark(orig)`** 再 **`upsertBookmark(line, note)`**，否则仅 **`upsertBookmark`** 更新备注；关弹窗（含取消）会 **`watch(addBookmarkOpen)`** 清空暂存行。

### 从列表跳转

- **`jumpToBookmark`**：跳转前 **`ensurePinBeforeRevealFindWidget`**（未激活书钉时记住当前滚动位置，与查找 / 高亮词 / 侧栏搜索一致）；再 `physicalLineToDisplayForReader`（只读）后调用 **`ReaderMain.jumpToBookmarkLine`**：经 **`computeScrollTopForLineAtViewportSlot(..., READER_BOOKMARK_JUMP_SLOT_FROM_TOP)`** 将目标行落在视口第 2 条字高带，为黏性章节条留白（不随 `headingLevel` 变化）。

### 侧栏列表（`BookmarkListPanel.vue`）

- **章节名**：`useAppBookmarkPins` 对每条书签用 **`pickActiveChapterIdx(chapters, line)`**（`reader/chapterIndex.ts`）；**只读**下先将存盘物理行换为 **Monaco 显示行** 再查章，**编辑态** 下用存盘行直接查（与章节表 `lineNumber` 坐标一致）。无匹配或标题去空后无字则不展示章节行。
- **正文预览**：**只读**下经 **`physicalLineToDisplayForReader`** 取 **`getDisplayLineContent`** 展示行文本；**编辑态**取 **`getPhysicalLineContent`**。从该书签行起向下扫描，取首个 **trim** 非空内容；否则展示「（空行）」类占位。
- **备注占位**：有非空备注照常显示；**无备注** 若能显示章节名则不渲染「无备注」；无备注且无章节名时仍显示「无备注」斜体占位。
- **样式**：**`.bookmarkChapter`**（11px、字重 600、`opacity: 0.78`、单行省略）、**`.bookmarkContent`**（11px、斜体、`opacity: 0.7`、单行省略）；**`.bookmarkMain`** 内 **`gap: 2px`**，备注/章节/正文行统一 **`line-height: 1.35`**，与弹窗预览对齐。
- **右键菜单**：**`AppContextMenu`** 置于 **`<Teleport to="body">`**，组件根上 **`data-fullscreen-sidebar-float`**（与 **`FileListPanel`** 等侧栏 Teleport 菜单一致），避免侧栏滚动容器 **`overflow`** 裁切；坐标仍用 **`clientX` / `clientY`**（视口坐标）。
- **更多菜单**：导出 / 导入 JSON（`readerBookmarkExport.ts`；默认名见 **「彩读书包」→ 各模块单独导出文件名**）。

### 添加 / 编辑书签弹窗（`AppOverlays.vue`）

- **`addBookmarkDialogPreview`**（`useAppBookmarkPins` 计算属性）：仅在 **`addBookmarkOpen`** 时有效；内容含 **`chapterTitle?`**、**`content`**，推导行号与 **`confirmAddBookmark`** 一致；依赖 **`chapters`、`totalLineCount、lastProbeLine、readerEditMode`** 等以便章节重建、滚动探针、流式增行时刷新。
- **布局**：备注 **`textarea` 上方** 为预览区；章节名与正文样式、行距、间距与侧栏 **`.bookmarkChapter` / `.bookmarkContent` / `.bookmarkMain`** 一致；正文预览单行省略、**`title`** 悬停可看全文。
- **编辑态 footer**：左下角 **「更新为当前行」**（`canBookmark` 为 false 时禁用），经 **`@update-bookmark-to-current-viewport-line`** 调用 **`updateEditingBookmarkToCurrentViewportLine`**：仅更新 **`stagedEditingBookmarkLine`**，与备注一样在点 **「保存」** 时一并落盘；**「取消」** 关弹窗会清空暂存。仅 **`editingBookmarkLine != null`** 时显示。

### `App.vue` 数据流

- **`useAppBookmarkPins`** 除原有依赖外传入 **`chapters`** ref，供列表与弹窗推断章节名。

## 阅读器表面配色

- **入口**：**配色**弹窗（**F6** / 更多菜单 / 顶栏高亮菜单）→ **「阅读器」** 页（**`ColorSchemeReaderPanel.vue`**）。
- **必选色**：**背景色**、**章节标题**、**正文**（无开关）。配色表末行（「数字」之下）为**背景图**预览格（形如拾色器，仅 contain 居中显示当前主题选中的图，不套叠层参数；「无」则为空）。点击进入背景图列表，返回按钮为 **「返回配色」**。有背景图时预览格右侧显示 **「选项」** 图标（可用性与背景图页 footer「选项」相同），点击弹出叠层调节。footer **「开关」** 中可关背景图叠层（亮暗共用；关时保留所选图）。取色浮层可切 **色盘** / **HSL**（HSL 适合在基调上微调色相 / 饱和度 / 亮度；落盘仍为 `#RRGGBB`；同一窗口内所有拾色器共用该模式）。hex 旁 **滴管** 进入全屏取色：主进程截屏后以覆盖层显示冻结画面与放大镜格子（系统十字光标）；左键把取样色写回草稿，Esc / 右键取消；`C` 复制指针所在屏的当前显示值，`Shift` 在 HEX 与 RGB 之间切换（进程内记住上次格式，下次进入沿用）。坐标为物理像素（与截图像素、Snipaste 一致）。配色弹窗保持打开，可对着预览取色（macOS 首次可能需授予屏幕录制权限）。其它入口请调 **`pickScreenColor()`**（`utils/pickScreenColor.ts`），返回 `#rrggbb` 或 `null`。
- **可选 token 色**（引号内 / 括号内 / 标点 / 特殊标记 / 数字 / 字母）：默认**开启**并使用独立色；**关闭**时阅读器回退为**正文色**（便于如读英文书时临时关掉「字母」上色），已选色值仍保留。开关在 footer **「开关」** 中修改（亮暗共用、不属于某一套方案；同页含**背景图**开关）。配色弹窗预览：**「配色」** 时始终显示各 token 独立色与背景图（忽略开关）；**「开关」** 与方案列表按开关回退（关背景图时上方预览不叠图；方案卡片仍显示该方案的图）。
- **成对括号**（`txtrTextMonarch`，内侧 `txtr.bracketInner`）：`()` `（）` `〔〕` `﹝﹞` `[]` `［］` `【】` `〖〗` `{}` `｛｝` `《》` `〈〉` `＜＞` `«»` `‹›`。半角 `<>` 仍作比较标点。未配对闭符在 root 走标点色。与语音朗读过滤的小/中/尖括号范围对齐。
- **亮/暗主题**：表面**色值**亮/暗各一套；token **开关**亮暗共用一份。配色弹窗标签页右侧图标按钮可切换主题色（立即生效，不必点「应用」）。方案列表只显示**当前主题**的方案。进入配色表或背景图页时不可切换主题（F2 / 顶栏同样无效），返回列表或开关页后恢复。
- **生效路径**：`App.vue` 按选中方案 id 从内置/用户方案取出色板，再经 **`resolveEffectiveReaderPalette`** 得到 **`effectiveReaderSurfaceLight` / `effectiveReaderSurfaceDark`** 传给 **`ReaderMain`**；`readerInlineDecorations.buildTxtrTokenRules` 使用有效色。
- **持久化**（**`colorTxt.ui.settings`**）：
    - **`readerPaletteSelectedIdLight` / `readerPaletteSelectedIdDark`**：当前选中方案 id。阅读器与预览都按此 id 取色；**找不到**（错主题、已删）回退该主题内置 **「默认」**。**无 id** 且盘里有旧 **`readerPaletteOverridesLight` / `Dark`**（9 色与当前「默认」不同）时，读入时生成名为 **「自定义」** 的用户方案并选中（稳定 id `u-legacy-light` / `u-legacy-dark`），随后不再写覆盖色。
    - **`readerPaletteUserPresets`**：用户添加的命名方案（`{ id, name, theme, palette }`，palette 为 9 色 + `textureId`；不含 token 开关）。自定义配色只写在这里。
    - **`readerPaletteColorEnabledOverrides`**：仅写入为 `false` 的 token 键（亮暗共用一份；默认全开；旧数据的 Light/Dark 两份在读取时合并，任一为关则关）。不再写入已废弃的 **`readerPaletteOverridesLight` / `Dark`**。
- **配色方案**：阅读器页**默认显示**方案卡片网格（上方预览不变）。列表只含**当前主题**的内置与用户方案。卡片背景为该方案「背景色」，该方案有背景图时叠同一张图（用该图**当前主题**那一侧叠层；填充为「原始」时卡片改用「包含」，避免大图只露出一角）；第一行名称为「正文」色，第二行为其余 7 色色块（章节标题 / 引号内 / 括号内 / 标点 / 特殊标记 / 数字 / 字母）；选中卡片边框为 **`--accent`**。用户方案卡片左上角有彩色色盘图标（不可点，标识可改配色）；悬停时右上角出现 **重命名**、**删除** 图标按钮。内置方案定义见 **`readerBuiltins/palettes.ts`**（亮暗分列；文档不列名单，增删改以该文件为准）。打开面板时亮、暗分别按已存 **id** 查找同主题方案；**找不到**则选该主题 **「默认」**。从没有方案 id 的版本升级时，若有旧覆盖色会先迁成 **「自定义」** 再选中。footer **「配色」** 进入取色表（内置方案禁用，需先 **新增亮色/暗色配色方案**；预览忽略开关、始终上色）；**「开关」** 显示全部色值但拾色器禁用，只改 token 开关（预览按开关回退）；再点 **「返回」** 回到列表。用户方案上改色值或选图会**直接写入该方案**。进入编辑后不显示 **「新增亮色/暗色配色方案」**。列表态 **「新增亮色/暗色配色方案」** 弹出 **方案名称**（默认「原方案名 副本」），确定后按当前选中方案生成**当前主题**的用户方案、选中（滚到列表中间；末项停在底部）并进入 **配色**。点选方案只替换**当前主题**的色值与选图草稿，**另一主题与 token 开关不变**。取消 / Esc 在有未应用改动时确认。打开方案列表、退出编辑回到列表时将当前选中项滚到容器中间。
- **导入 / 导出**：配色弹窗标签页右侧 **更多** → **导出配色** / **导入配色** / **导出当前配色方案**（当前为**内置方案**时该项禁用）。导出为 zip（`color-scheme.json` + 方案用到的自定义背景图 `textures/`）；默认文件名见 **「彩读书包」→ 各模块单独导出文件名**。**导出配色**含全部用户方案，以及当前面板可见的高亮色 / 标注色；**当前配色方案**只含选中那一套用户阅读器方案及其引用的图。JSON 里已应用亮/暗色板带 **`textureId`**，另有 **`selectedIdLight` / `selectedIdDark`**，用户方案为 `{ id, name, theme, palette }`，引用到的图在 **`textures`** map（自定义含 `fileName` 与顶层 `light` / `dark`）。导入合并用户方案与图库项（同 id 覆盖、其余保留），并按包内 **`selectedIdLight` / `selectedIdDark`** 选中方案（无 id 或找不到则选 **「默认」**），点 **「应用」** 后写入。
- **应用**：草稿改动与方案增删改名均在点 **「应用」** 后写入。要点回出厂色，在列表中选「默认」。

### 阅读区背景图

- **入口**：配色弹窗「阅读器」→ **配色** 表「背景图」预览格（`ColorSchemeReaderPanel` pane `bg`）。本地阅读器与找书阅读器共用。内置方案需先「新增亮色/暗色配色方案」才能进配色表。
- **范围**：只叠在阅读表面（`ReaderMain` 正文、全屏/极简垫底、找书阅读区）。书库、文件列表、找书书架仍用 `--bg` / `--panel`，无背景图。
- **与配色方案**：图库（内置 + 自定义文件 + 每张图**亮/暗各一套**叠层）全局一份。**选中哪张图**记在**每套配色方案**上（亮色方案与暗色方案各自一张；各内置方案的默认选图见 **`readerBuiltins/palettes.ts`** 的 `textureId`）。点选方案时草稿与预览立即套用该方案的选图；点「应用」后写入当前阅读器。换方案可以有的有图、有的没有。**是否叠图**仍由 footer **「开关」** 的「背景图」开关控制（亮暗共用，默认开；关时保留所选图；方案列表上方预览与阅读器不叠图，方案卡片与「配色」预览仍叠图）。**内置图**叠层不可改（要调请 **「生成副本」**）。选项面板只改**自定义图**当前主题那一侧（图库级，不随方案复制；亮色方案与暗色方案选同一张自定义图时各改各的一侧）。
- **内置预设**：目录与叠层默认见 **`readerBuiltins/textures.ts`**（文档不列名单）；资源在 `src/renderer/public/reader-textures/`。
- **调节**：配色表背景图预览格右侧 **「选项」** 图标，或背景图页 footer **「选项」**，弹出同一套叠层调节（写入当前主题那一侧）。全局默认：**混合模式**「正常」、**不透明度** 100%、**填充方式**「填满」、**平铺**关、**对齐方式**右上。混合模式还可选正片叠底 / 变亮 / 叠加 / 柔光 / 滤色 / 变暗。填充另有「包含」「原始」（1 图像素 = 1 屏幕像素，会抵消系统 DPI / 窗口缩放，避免在 125%、150% 显示器上被放大）。内置图各项可选的 **`light` / `dark`** 叠层写在 **`textures.ts`**，未写的一侧用上述全局默认。选「无」时不显示配色表「选项」图标；选内置图时图标与 footer **「选项」** 禁用（提示先生成副本）。切到「无」或内置图时若选项浮层已开则关闭。
- **生成副本**：footer **「选项」** 右侧 **「生成副本」**（当前为「无」时禁用）。弹出名称框（默认 `{原名} 副本`，取消则不复制），将当前选中图复制为自定义图（拷贝亮/暗两套叠层）。**自定义图**只新增图项（新 id），**共用同一文件**；**内置图**会把像素写入 `userData/reader-backgrounds/`。并在当前主题下选中该副本。删除自定义项时，仅当没有其它图项引用同一文件才删盘。
- **自定义导入**：footer **「导入图片」** 可多选（png / jpg / jpeg / webp），复制到 `userData/reader-backgrounds/`，以 `colortxt-local://` 显示。点「应用」后写入；取消时丢弃本次会话新导入且未保留的文件。
- **持久化**（`colorTxt.ui.settings`）：图库在 `readerBackground`（`enabled`、`custom[]` 每项含 `id` / `name` / `fileName` / `light` / `dark`；内置叠层不落盘覆盖，以 `readerBuiltins/textures.ts` 为准）。当前已应用选图记在选中方案上（内置方案目录或 **`readerPaletteUserPresets[].palette.textureId`**）；内置方案默认为「无」或该方案指定的图。WebDAV 同步元数据与 **`Main/reader-backgrounds/`** 下的自定义图文件（按文件名 + 大小增量）；对端缺少文件时该槽不显示图（选中则回退为无叠层）。不兼容旧版单套 `layer` 存盘（读入时该侧回退内置/全局默认）。
- **配色导入/导出**：zip 含各方案所选图 **id**（已应用色板与用户方案 `palette.textureId`）、引用到的图项（`textures`，顶层 `light` / `dark`）与自定义图文件。
- **实现**：`html` 上 `--reader-bg-image` 等变量，`.readerSurfaceBg::before` 叠层。全屏/极简时只在最外层容器画底色+纹理，内层 `ReaderMain` / Monaco 透明透出（避免正文列与两侧留白各叠一层导致图案错位）。粘性章节条用实心底色挡住滚动正文，并叠同一张纹理（对齐阅读表面），**不投下阴影**以免切开纹理。条内 `.sticky-line-content` 须保持 Monaco 的 `position: absolute`（不要给标题行加 `position: relative`）。**每一行**也要实心底色 + 对齐纹理：Monaco 替换子级标题时末行会带着更低 `z-index` 上滑，没有行背景就会叠进父级。`::before { z-index: -1 }`（配合行上 `isolation: isolate`）把纹理垫在标题下。对齐只写在 `.sticky-widget` 上（`--reader-bg-align-*`），各标题行继承并用 `--sticky-line-dx/dy` 扣掉行内偏移。缩放时由 **`ResizeObserver`**（阅读表面 + 粘性条，布局后、绘制前）和 **`flushReaderBackgroundStickyAlign`**（`resize` / Monaco `onDidLayoutChange` / 滚动）立刻重算，不用 rAF（rAF 在布局前跑会用上一帧坐标，看起来像延迟对齐）。子级标题刚好替换时条高往往不变（`ResizeObserver` 不触发），且 Monaco `_renderStickyScroll` 是 **async**，滚动里那次对齐会早于换行；对 `.sticky-widget` 做 **`MutationObserver`**（子树 childList / style），在 DOM 真正换完后再写偏移。条尚未进 DOM 时仍用 **`scheduleReaderBackgroundStickyAlign`** 重试若干帧。小地图仍用实心 `--reader-bg`（Canvas 不支持透明底）。滚动条轨道：只读透明，**编辑模式**改用实心 `--reader-bg`（与小地图一致）。全屏时钟无底色。

## 自定义高亮词与高亮色

- **高亮色（全局、按主题）**：
    - 默认亮/暗两套颜色列表见 `constants/highlightColors.ts`（`DEFAULT_HIGHLIGHT_COLORS_LIGHT` / `DEFAULT_HIGHLIGHT_COLORS_DARK`）。
    - 在 **`ColorSchemePanel` →「高亮色」** 页编辑；可 **拖动「移动」手柄** 调整槽位顺序（确定后数组顺序即 Monaco 高亮槽位索引）；可增删行（不少于 **`MIN_HIGHLIGHT_COLORS`**）；确定后经统一 **`apply`（`ColorSchemeApplyPayload`）** 写入 `App.vue`（**`onApplyColorScheme`** 一次落盘），并持久化到 **`colorTxt.ui.settings`** 的 `highlightColorsLight` / `highlightColorsDark`。
    - 当前 shell 主题为 `vs` 时用亮色表，`vs-dark` 时用暗色表（与阅读器表面色主题一致）。
- **数据模型（词组）**：
    - **`HighlightWordsByIndex`** = `Record<string, string[][]>`：颜色槽位索引字符串 → **词组列表**；每个词组为 `string[]`（≥1 个词，顺序有意义）。
    - **`normalizeHighlightWordsByIndex`**（`fileMetaStore.ts`）兼容旧版扁平 **`string[]`**（每个词迁成单词语组 `[词]`）。
    - 侧栏一行对应一个词组（**`HighlightListTerm`**）：**`terms`**（展示/跳转）、**`storedTerms`**（持久化/CRUD）、`color` / `colorIndex`、`scope`（`book` | `global`）、`isFavorited`。
    - 列表稳定 key：**`highlightGroupListKeyBase`** 对词组做**排序后拼接**（词序无关，组内重排不改变 key）；同组同时存在收藏与本书各一条时 key 再含 `scope`。
- **自定义词（本书 + 已收藏全局）**：
    - **本书**：选区添加 / 侧栏添加与编辑写入该文件 **`colorTxt.file.meta`** 的 **`highlightWordsByIndex`**。与书签类似先改内存，在切书、`rememberCurrentFileLine`、关窗卸载等路径随 `fileMetaStore` 落盘。
    - **已收藏（全书通用）**：侧栏点击「收藏」后写入 **`colorTxt.ui.settings`** 的 **`highlightWordsByIndexGlobal`**，结构与本书词表相同。清空时须写入空对象 `{}`（合并落盘跳过 `undefined`，否则关窗后旧收藏会回来）。
    - **存盘 vs 展示**：持久化为 **`storedTerms`**（**只读**下为物理原文区间，**编辑态**与 Monaco 一致）；展示层经 **`refreshReaderHighlightDisplayLayer`** / **`applyTextDisplayConvertsToHighlightWordsByIndex`** 得到侧栏与 Monarch 用的 **`terms`**。
    - **阅读器上色**：渲染前合并 global + 本书词表并**压平**为词→色（**同一词本书颜色优先**）；Monarch 规则使用**展示层**词表（**`readerDisplayHighlightWordsByIndex`**）。
    - **选区浮层**：仅根据**本书**词表判断「是否已是高亮词」；仅存在于已收藏的词在正文中仍会高亮，但浮层仍可按新词加入本书（可与收藏并存，侧栏可显示两行）。未设置为高亮词时，点工具条「高亮词」或按 `1` 会用 **`highlightLastColor`**（上次选用的色槽，默认 0）自动添加并打开色盘；已是高亮词时仅打开色盘（与划线按钮逻辑一致）。
    - **取消收藏**：从全局移除；若本书尚无该词组则写入本书，若本书已有则只删全局条目。
- **侧栏「高亮词」**（**`HighlightListPanel.vue`** / **`HighlightTermEditModal.vue`** / **`useAppHighlightTerms.ts`**）：
    - **标题行**：启用 AI 阅读助手时左侧 **「AI 检索」**（见 [AI功能.md](./AI功能.md) → **「高亮词 AI 检索」**）；**添加**（打开添加面板）；**更多**（导入/导出本书与收藏 JSON）。
    - **添加 / 编辑面板**（**`HighlightTermEditModal`**）：标签输入（背景=阅读器背景、字色=草稿高亮色）、色盘改色、底栏取消/确定；标签可拖动排序（Sortable）；词多时**输入框内部滚动**（面板不滚）。
    - **列表展示**：已收藏在前、本书在后。词组 ≤2 词时整行 `词 | 词`；**>2 词**时摘要为 **代表词 + `+N`**（`N` = 其余词数）。点 **`+N`** **就地展开**（header：`共 N 个` + 编辑/收藏/移除；下方可滚动词列表）；点外部或 Esc 收起；同时仅一项展开。
    - **跳转**：点**单个词** → 字面量查找该词；点**整行**（摘要态）或展开态 **header** → 整组跳转（`buildHighlightFindQuery`：多词为转义后 `|` 连接的正则）。展开态词列表空白不触发整组跳转。
    - **拖放**（HTML5 DnD）：
        - **整项**拖到另一项 → **合并**（颜色/scope 以目标为准）。
        - **单个词**拖到另一项 → 将该词**移入**目标组。
        - **单个词**拖到列表外（未落到任一项）且原组为多词 → **拆分**为独立词组。
        - **同组内**拖到另一词前后 → **调整顺序**（经 `commitHighlightGroup`；展开态不因重排收起）。
    - **行操作**：编辑、收藏/取消收藏、移除（已收藏项无移除钮，须先取消收藏；移除前 **`appConfirm`**「是否移除该高亮词？」）。
- **导出 / 导入**：侧栏「更多」→ JSON（`readerHighlightExport.ts`）。导出 **`schemaVersion: 2`**（词组 `string[][]`）；导入仍接受 v1 扁平 `string[]`（经 normalize 迁成词组）。本书默认名 **`{书名}.highlights.json`**，收藏 **`favorite.highlights.json`**。
- **开关与语法**：
    - **`monacoCustomHighlight`** 存于 `colorTxt.ui.settings`。
    - 开启且存在有效词表时，`txtrHighlightMonarch.buildTxtrCustomHighlightMonarchRules` 生成 Monarch 规则（词组压平后更长词优先），由 `txtrTextMonarch` 注入 `txtr-text`；`readerInlineDecorations` 为对应 token 提供前景色（与槽位索引及 `highlightColors` 对齐）。
    - 关闭开关或无语词时不注入自定义规则。

## 阅读器标注与笔记

本节汇总**划线标注**、**笔记**、**标注色**、侧栏 **「笔记」** 列表与导出；与 **「自定义高亮词与高亮色」** 独立（高亮词走 Monarch 前景色，标注走 inline 装饰 + 动态 CSS）。

### 功能与入口

- **侧栏「笔记」**：活动栏 tab **`notes`**（`constants/readerSidebarTab.ts`）；面板 **`AnnotationListPanel.vue`**。
- **选区工具条**（**只读**）：选中文本或点击已有标注时出现 **`ReaderSelectionToolbar.vue`**，由 **`useReaderAnnotations.ts`** 驱动；**阅读器编辑模式**下不启用，且**不在 Monaco 上渲染划线/马克笔等 inline 装饰**（侧栏笔记列表仍可查看与跳转）。**点击模式**下正文不可选，工具条不会因选区出现。**找书阅读器**无高亮词、笔记与 AI 阅读助手：传 **`showSelectionAnnotationTools=false`**、**`aiFeaturesEnabled=false`**，无本地文件路径亦可弹出工具条，但不含「高亮词 / 马克笔 / 波浪线 / 直线 / 记笔记 / 问 AI」。
- **数字快捷键**（主键盘 / 小键盘）：`1` 复制、`2` 高亮词、`3` 马克笔、`4` 波浪线、`5` 直线、`6` 记笔记、`7` 查找、`8` 词典、`9` 翻译、`0` 问 AI；与工具条按钮显示条件一致（关配置、关自定义高亮、找书无标注、关 AI 时对应键不生效）。高亮词 / 划线为同键切换标注与取消。
- **笔记输入**：**`ReaderNoteInputPanel.vue`** 浮于选区旁，编辑 **`note.content`**。
- **配色 → 标注色**：**`ColorSchemePanel`** 第三页 **「标注色」**（`ColorSchemeLineationPanel.vue`）；亮/暗各一套，可增删与拖动排序（不少于 **`MIN_LINEATION_COLORS`**）；确定时与高亮色一并走 **`apply` → `ColorSchemeApplyPayload`**（`App.vue` **`onApplyColorScheme`** 一次落盘，避免分事件导致删色未写入）。

### 数据模型（`ReaderAnnotationRecord`）

持久化于当前书的 **`colorTxt.file.meta` → `readerAnnotations`**（`fileMetaStore.ts`）：

| 字段 | 说明 |
| ---- | ---- |
| `id` | 稳定 UUID |
| `startPhysicalLine` / `startColumn` / `endPhysicalLine` / `endColumn` | 源文件**物理行 + 物理列**范围（含空行；列号为磁盘原文 1-based UTF-16，与书签行号语义一致；**不**随压缩空行/行首缩进/转换变化） |
| `text` | 创建/更新时在**物理区间**截取的原文快照，供失效校验与兜底展示 |
| `displayText?` | 可选：当时 Monaco **展示层**原文缓存；与 **`text`** 相同时 normalize 时可省略；运行时侧栏/导出优先 **`resolveAnnotationDisplayQuote`** live 截取 |
| `startDisplayLine?` / `endDisplayLine?` | **遗留**（旧版按展示行/展示列存盘）；读入时 **`migrateLegacyAnnotationToPhysicalColumns`** 一次性改写为物理列并剥离 |
| `lineation?` | 可选划线：`type` 为 `marker`（马克笔）/ `wavy`（波浪线）/ `straight`（直线）；`colorIndex` 对应当前主题标注色表下标 |
| `note?` | 可选笔记：`content`、`createdAt`、`updatedAt` |
| `stale?` | 物理区间 slice 与 **`text`** 不一致时标记（与展示层排版/转换无关）；侧栏显示「已失效」，可通过 **「清除失效笔记」** 批量移除 |
| `createdAt` / `updatedAt` | 记录时间戳 |

**保留规则**：至少存在 **`lineation`** 或 **`note`** 之一才保留记录。**移除划线**时若尚无笔记，**整条移除**（不留空壳）。

### 坐标映射与排版无关性

- **列映射**：**`annotationColumnMapOptions({ readerEditMode, leadIndentFullWidth })`** — 仅 **只读且开行首缩进** 时在物理列 ↔ Monaco 展示列间偏移；**编辑态**与未开缩进时 1:1。章节标题行经 **`chapterTitleExemptForPhysicalLine`** 豁免缩进列（与 **`chapter.ts`** 的 **`physicalOffsetToDisplayOffset`** 一致）。
- **Monaco 范围**：**`physicalRangeToMonacoRange` / `monacoRangeToPhysicalRange`** 结合 **`physicalToDisplay`** 行映射与上述列映射，供装饰、选区工具条、跳转共用。
- **失效判定**：**`validateAnnotationAgainstPhysicalSource`** 只在 **`physicalLineContents`** 上 slice 比对 **`text`**；切换压缩空行/行首缩进/简繁等**不**批量标 stale。
- **旧数据迁移**：**`normalizeReaderAnnotations`** 读入时对仍含展示列语义的记录调用 **`migrateLegacyAnnotationToPhysicalColumns`**（必要时 **`locatePhysicalRangeForStoredText`** 全文定位），失败则标 **`stale`**。

### 引用原文（`resolveAnnotationDisplayQuote`）

侧栏列表、导出 Markdown、存盘 **`displayText`** 均经 **`App.vue`** 的 **`annotationDisplayQuoteContextForUi`**（含 Monaco model、**`getDisplayLineContent`**、hit 表、列映射）调用 **`resolveAnnotationDisplayQuote`**：

1. **编辑态**：物理区间 **`text`**（与 Monaco 一致）。
2. **只读**：若未 stale — hit 表（与阅读器装饰同源，按展示行去重）→ Monaco **`getValueInRange`** → 展示行数组 → 存盘 **`text`**。截取结果**不 trim**，选区内的行首全角缩进原样保留。
3. 索引重建后 **`onAnnotationIndexRebuilt`** → **`annotationDisplayEpoch`** 驱动侧栏列表重算 quote。

### 标注色与上次选色

- **色表**：**`lineationColorsLight` / `lineationColorsDark`** 存于 **`colorTxt.ui.settings`**（`cacheStore.ts`）；当前 shell 主题为 `vs` / `vs-dark` 时阅读器与工具条使用对应表（与高亮色切换规则相同）。
- **上次选色**：**`lineationLastColors`**（`marker` / `wavy` / `straight` 各一 index）记住三种线型各自上次使用的色块；切换线型或新建划线时默认取对应 index。高亮词另有 **`highlightLastColor`**（单 index，存于同一 settings），新建高亮词时默认取该值。
- **下标解析**：**`clampLineationColorIndex`** 将无效或**越界** index 回退到**当前色盘最后一色**（用户删色后旧 index 仍可读回 raw 值，渲染时再 clamp）。装饰构建（`readerAnnotationDecor.ts`）、工具条色块（`ReaderSelectionToolbar.vue`）、持久化 normalize（`readerAnnotations.ts`）均按**当前色盘长度**解析。

### 交互要点（`useReaderAnnotations.ts`）

- **新建划线**：在选区上选线型 + 色块 → upsert；更新 **`lineationLastColors`** 对应线型 index。
- **点击已有标注**：绑定 draft 到该条，**不改变**编辑器选区；工具条展示当前线型/色与笔记状态。
- **移除划线 / 取消高亮词**：色盘最前「移除」图标，或数字快捷键再次切换；取消后**关闭色盘**（工具条仍可保留）。无笔记时整条标注移除；有笔记时仅去掉 **`lineation`**。
- **记笔记**：**`hasNote`** 为 true 时「记笔记」按钮高亮（`selAction--noteActive`）；若同时有划线，笔记图标颜色跟标注色。
- **查找**：主工具条「记笔记」后、「问 AI」前（需设置开启，**默认显示**）；**关闭**工具条后按 **`findTarget`** 处理选区文案：**`findBar`**（默认）→ **`ReaderMain.openFindWithSearchString`**；**`sidebarSearch`** → 展开侧栏「搜索」并填入查询。找书窗口无全文搜索侧栏：**不展示**该配置项，但若主界面已设为「全文搜索」，找书内点击「查找」仍**回退查找栏**。
- **词典**：主工具条「查找」后、「问 AI」前（需设置开启，**默认显示**）；点击后**关闭**工具条并打开 **`ReaderDictionaryPopup`**（见 **「词典查词」**）。
- **翻译**：词典后、「问 AI」前（需设置开启，**默认显示**）；点击后**关闭**工具条并打开 **`ReaderTranslatePopup`**（见 **「选区翻译」**）。
- **问 AI**：需 AI 总开关且设置开启；将选区/标注原文格式化为 blockquote 引用，经 `App.vue` **`onAskAiWithQuote`** → 侧栏 **`prefillQuotedText`**；**不关闭**工具条（短暂 **`suppressToolbarUntilMs`** 抑制误关）。
- **工具条显示项**（**设置 → 阅读 → 工具条**）：`selectionToolbarButtons`（`copy` / `find` / **`dictionary`** / **`translate`** / `askAi` / **`findTarget`**）控制选区工具条按钮显示与「查找」应用目标（查找栏 / 全文搜索，默认查找栏）；**可配置按钮默认全部开启**。主界面设置页以工具条预览 + 左上角复选框，以及与定时滚动「范围」同款的 **`RadioGroup`**；找书设置 **`showFindTargetOption=false`** 隐藏应用目标，**`showAnnotationTools=false`** / **`showAskAi=false`** 预览亦不展示高亮词 / 划线 / 记笔记 / 问 AI。可配置按钮全部关闭且无标注类按钮时**不弹出**工具条（避免空白条）。
- **浮层钳制**：相对选区水平居中；**优先**钳在阅读区；仅当阅读区钳制后右侧仍会被**窗口**裁切时，水平改按窗口钳制（可伸入侧栏）。垂直方向：上下都能放下时优先**可用空间更大**的一侧（`computeFloatPlacement`）；两侧都放不下时同样取空间更大侧并钳制高度。
- **Monaco 查找栏**：在 **`.find-widget`** 内点击/拖选**不**弹出选区工具条（**`isFindWidgetTarget`**，避免误触发）。
- **视口装饰**（**只读**）：**`readerAnnotationDecor.ts`** 仅为视口附近标注创建 inline decoration，并按标注色表注入 CSS；**`rebuildAnnotationIndex`** 建 hit 表后 **`syncAnnotationViewportDecorationsNow`** 随滚动增量更新。**编辑模式**下跳过索引与装饰（**`clearAnnotationViewportDecorations`**），退出只读时自动重建。空白物理行不建 hit（压缩空行时它们会映射到下一段正文，否则原文与悬停会重复）。笔记悬停由 **`txtr-text` HoverProvider** 提供（不按行挂 `hoverMessage`），折行只出一个框。

### 侧栏列表（`AnnotationListPanel.vue`）

- 行数据经 **`buildAnnotationListRows`** + **`groupAnnotationListRowsByChapter`** 按章节分组；组标题**粘性**（样式与章节/书签列表对齐）。
- **跳转**：**`onJumpToReaderAnnotation`** 先 **`ensurePinBeforeRevealFindWidget`**（与高亮词 / 书签一致），再 **`jumpToAnnotationRange`**。
- 组内、组间均按**物理行号**排序；项内**原文预览**经 **`resolveAnnotationQuoteForUi`**（包装 **`resolveAnnotationDisplayQuote`**）与阅读器装饰对齐。
- **笔记项**：原文在上、笔记正文在下（左侧竖线注释块，样式同原「原文」槽）。
- **右键**：移除单条。
- **更多菜单**：导出 Markdown / JSON、导入 JSON、清除失效笔记、清空全部（经 `App.vue` + `readerAnnotationExport.ts`；Markdown 导出注入 **`resolveQuoteText`**）。

### 导出格式

- **JSON**：`schemaVersion: 1`，含 `exportedAt`、`bookPath`、`bookName`、`annotations` 数组；默认文件名 **`{书名}.notes.json`**（见 **「彩读书包」** 文件名表）。
- **Markdown**（`buildReaderAnnotationsExportMarkdown`）：
    - 标题 `# 《{书名}》阅读笔记`（书名去掉 `.txt` / `.md` 等正文书后缀）。
    - 按章节 `## {章节名}` 分组；组内按行号序。
    - 有笔记：**`💡 {原文}`**，下方 `> {笔记正文}` blockquote。
    - 仅划线：**`✨ {原文}`**。
    - 失效项前缀 **`[已失效]`**。
    - 文末 `---` 与 `*导出于 {本地时间}*`。
    - 默认文件名 **`{书名}.notes.md`**。

## 词典查词

选区旁本地 / 网络词典查询；主界面与找书阅读器共用。

### 功能与入口

- **选区工具条「词典」**（**只读**）：需 **`selectionToolbarButtons.dictionary`**（默认开）；点击后关闭工具条，打开 **`ReaderDictionaryPopup.vue`**。
- **词典管理**：**`DictionaryManageModal.vue`**（浮层齿轮 / 设置 → 阅读 → 词典管理）；可拖动排序、开关、导入本地词库、重命名 / 删除本地项、配置缓存目录。
- **设置 → 代理**：主界面与找书「代理」共用配置（见 [书源找书.md](./书源找书.md) → **§6.11**）；联网词典（Wiktionary / Wikipedia）经 **`fetchViaChromiumNet`**，跟随该默认代理。

### 设置与持久化

- **`dictionarySettings`**（`colorTxt.ui.settings`）：`providerOrder` / `providerEnabled` / `importedDictionaries` / `localCacheDir`；常量与 merge 见 **`constants/dictionarySettings.ts`**，类型见 **`shared/dictionaryTypes.ts`**。
- **内置网络词典**：`builtin:wiktionary`、`builtin:wikipedia`（默认启用）。
- **本地词库**：导入后写入 **`localCacheDir`**（空则默认 **`userData/dictionaries`**，见 **`utils/defaultCacheDirs.ts`**）；支持 StarDict / MDict（`.mdx` + 可选 `.mdd` / `.css`，依赖 **`mdict-js`**）/ DICT / Slob / BGL；新导入项插入列表**顶部**。
- 找书窗与主界面共用同一份 `dictionarySettings`（各窗内存独立，打开时读最后保存值）。

### 查词流程

1. 浮层列出全部已启用 provider，先显示「查询中」。
2. **本地**按顺序**串行**查；**网络**（Wiktionary / Wikipedia）**并行**查；每本词典完成后单独填入或移除占位。
3. IPC：**`dictionary:lookup` / `dictionary:import` / `dictionary:remove`**（`registerDictionaryIpc.ts` → `dictionaryService.ts`）。
4. 英文 Wiktionary 走 REST definition API，结果格式化为 HTML；中文词条解析 wikitext（拼音 + 释义列表）；Wikipedia 用 summary `extract_html`。
5. MDX 释义经 **`simplifyMdictHtml`** 去掉 script 与尾部 **`\0`**；若有配套 **`.mdd` / `.css`**，再经 **`resolveMdictResources`** 把相对路径图片、`sound://` 语音改成 `data:` URL，并注入样式；其中 **Ogg Speex（`.spx`）** 经 **`speexToWav`**（`@caitun/speex`）转成 WAV。
6. 浮层 HTML 结果在 **Shadow DOM** 中渲染（避免词库 `<style>` 污染整页）；带 **`dictSound`** 的发音链接可点击播放；带 **`dictEntry`**（`entry://` / `bword://`）的交叉引用在**该词典卡片内**跳转查词（不重查其他词典），卡片顶栏可返回上一词条。暗色主题下，对带硬编码配色 / 自带 CSS 的词库使用浅色底板；Wikipedia / Wiktionary 等应用自绘 HTML 仍跟随主题色。浮层打开时锁定位置与最大高度，输入框 `focus({ preventScroll: true })`。

### 浮层交互（`ReaderDictionaryPopup`）

- 顶栏：改词输入 +「查询」+ 管理齿轮；点外部 / Esc 关闭；无关闭按钮。点外部关闭时**仅**忽略 z-index 更高的 AppModal（如词典管理）；找书阅读器本身也在 AppModal 内，点击阅读区仍会关闭浮层（`isPointerOnAppModalAbove`）。
- 结果卡可折叠；打开或重新查询时**结果区滚回顶部**。
- 几何：**`useReaderAnnotations.applyDictionaryPopupPlacement`** — 钳在阅读区，`maxHeight` 随可用空间与实测高度更新；方向策略同工具条（空间更大侧优先）。

| 设置 → **AI 阅读助手** → 快速提问 | 行尾 **移动** 手柄 | **`AIConfig.quickQuestions`**（`string[]`） | 并行 **`quickQuestionRowIds[i]`**（与问题文案数组同序） |

原先各处的 **上移 / 下移** 按钮已统一为 **移动** 图标触发器；仅 **1 项** 时手柄禁用（`enabled` / `:disabled`）。

### 角色卡排序（与其它列表的差异）

- **Sortable 选项**：`forceFallback: true`、`fallbackOnBody: true`、`fallbackTolerance: 8`；`filter` 排除按钮、输入框及 **`.cardShell.flipped`**。
- **视觉**：进入拖动时 ghost 放大 + 倾斜弹簧回正；松手后克隆层 **`translate` 直线插值** 飞回落位格（约 280ms）。仅 **正面** 可拖动，故不再同步背面 **`.backScroll`** 的 scroll 快照。
- **列表滚动**：拖动时不对 **`characterMainScroll`** 使用 `overflow: hidden`，避免松手后滚动条异常。
- **实现文件**：`CharacterSidebarPanel.vue`（网格样式、`cardGrid--reordering`）、`CharacterRosterCard.vue`（`onReorderDragStart` 等）、`CharacterEditDrawer.vue`、`useCharacterRosterReorder.ts`、`useCharacterPortraitFs.ts`、`characterCardTiltDom.ts`。

#### 为何不支持背面拖动排序

角色卡与其它「表格行 + 移动手柄」列表不同：**整卡**在 **`preserve-3d`** 翻转层（**`card__flip` / `rotateY(180deg)`**）内展示正反面，背面还有 **`.backScroll`** 内层滚动。

在 Electron/Chromium 下曾尝试让 **翻面状态** 也能 Sortable，但始终难以同时满足 **3D 翻面** + **拖动排序**，冲突点可能在于 **3D 命中与跟手层**，背面经 **`backface-visibility: hidden`** 与 **`rotateY(180deg)`** 叠在翻转容器内；Sortable 即使用 **`forceFallback`** 把克隆挂到 `body`，指针按下/移动阈值与占位 ghost 的坐标仍易与 **倾斜层（`card__tilt`）**、相邻卡 **`:hover` z-index** 互相干扰。

最终产品策略为：**仅正面可排序，背面须先点击翻回**（`useCharacterRosterReorder` 的 **`isReorderDragFiltered`** 在 slot 内存在 **`.cardShell.flipped`** 时返回 true）。

**用户操作**：在背面查看角色信息时，**先点击卡片翻回正面**，再按住卡片拖动排序（与其它列表的 **移动** 手柄不同，角色卡无单独手柄图标）。

**代码落点**：`useCharacterRosterReorder.ts` → **`isReorderDragFiltered`**（注释：*3D 翻面背面无法可靠触发 Sortable*）；正面 **`card__flip` 的 `@click`** 仍负责翻面，Sortable **`filter` + `preventOnFilter: true`** 避免误触角标按钮。

### 章节规则表：表头与滚动条

**`ChapterRulePanel.vue`** 将 **`<thead>`** 与 **`<tbody>`** 拆成上下两张等宽表（共用 **`colgroup`**）：表头固定，**`.tableBodyScroll`** 单独 **`overflow-y: auto`**，滚动条仅覆盖规则行区域。表头容器经 **`ResizeObserver`** 读取 tbody 滚动条占位宽度，必要时 **`padding-right`** 对齐列宽。

### Vue 与 Sortable 协作注意

- **勿用数组下标作 `:key`**：Sortable 会先改 DOM，下标 key 会导致序号/输入框内容与行错位；须用 **随数据移动的 stable id**（见上表）。
- **高亮色** 草稿为 **`HighlightColorRow { id, color }`**，排序后调用 **`remountHighlightSortable()`** 重建 Sortable。
- **标注色** 草稿为 **`LineationColorRow { id, color }`**，排序后调用 **`remountLineationSortable()`** 重建 Sortable（`ColorSchemeLineationPanel.vue`）。
- **快速提问** 持久化仍为 `string[]`，UI 层维护 **`quickQuestionRowIds`**，拖动时与文案同步 **`splice`**。

## 摸鱼模式

独立无框透明覆盖层（`stealth-reader.html` / `StealthReaderApp.vue` / `src/main/stealthReader.ts`），**不**改 `ReaderMain` / Monaco。已接入**主阅读器**与**找书阅读器**（找书按当前章热换正文）。

- **入口**：顶栏 / 找书阅读器「更多 → 摸鱼模式」（`icons.stealthMode` ← `emituofo.svg`）；窗口快捷键 **`enterStealthReader`**（默认 **F9**）。主窗无打开文件、找书无本章正文时菜单禁用。主窗与找书快捷键面板均可展示/改键。
- **进入**：源窗把正文、视口行、章节快照经 IPC 交给主进程；源窗口 `hide` + `setSkipTaskbar(true)`；覆盖层 `showInactive()`。主阅读器传整书 TOC；找书传**当前章**并附带 `hasPrevChapter` / `hasNextChapter`。失败时 toast（无正文、已在摸鱼中等）。**首次**无已存窗位时对齐阅读区屏幕矩形；之后用 `colorTxt.stealth.settings.bounds`。**全局单例**：其它窗进入时先退出当前会话。
- **退出**：右键「退出摸鱼模式」或全局退出键（默认与进入键同为 F9，仅摸鱼期间注册）；`stealthReaderExit(line)` → 恢复源窗并 `jumpToLine`。macOS 上进入时为了盖住全屏空间会藏起程序坞图标，退出时 `app.dock.show()` 把图标恢复。
- **找书切章**：覆盖层在章边界（或贴边再滚/翻页）且 `hasPrev/Next` 为真时通知源窗换章；源窗 `loadChapter` 后 `updatePayload`，覆盖层经 `reloadPayload` 拉取 pending 正文。切章中显示「加载中」+ 弹跳点；失败/无邻章由 `chapterNavSettled` 解除加载态。贴边上滚切上一章可 `anchor: end` 落章末；上一章快捷键仍落章首。
- **窗口**：`frame: false`、`transparent`、`skipTaskbar`、`alwaysOnTop`（`screen-saver` + 相对层级）、Windows `type: 'toolbar'`、`focusable: false`、`resizable: false`（边缘缩放走 `setBounds`）。位置钳制用显示器 **`bounds`**。拖动超阈值则移动（移动亦走 **`setBounds`** 钉死逻辑宽高，避免 Win11 上 **`setPosition`** 清掉 **`setShape`** / 尺寸漂移），否则左半上一页 / 右半下一页。Windows 透明相关钉 **Electron 35.4.0**。Windows 无边框窗有系统最小高度（约标题栏高）；低于该高度时用 **`setShape`** 裁出逻辑尺寸，渲染根节点按逻辑宽高排版，以便缩到单行。Win11 点任务栏或关其它窗后可能把覆盖层压到任务栏下：指针进入任务栏区域时立刻重申置顶，并周期兜底 **`setAlwaysOnTop` + `moveTop`**。打开后正文仍用设置中的背景；其上蒙一层半透明绿色**点按提示**（左「上一页」/ 右「下一页」），**点击窗口任意处**关闭提示（该次点击不翻页）；热换章不重启提示层。
- **边缘缩放光标**：热区与拖缩放一致，四边 **4px**、四角 **6px**（角盖在边上）。Windows / Linux 用 CSS `ns-resize` / `ew-resize` / `nesw-resize` / `nwse-resize`。macOS 上 `focusable: false` 的窗不会套用 CSS cursor，焦点在其它应用时渲染进程也收不到 `mouseMoved`：主进程按屏幕坐标命中同一热区，经 **`macNsCursor.ts`** 改系统光标（窗口保持不可聚焦，不把应用带到前台）。实现见 [开发构建.md](./开发构建.md) → **`stealthReader.ts`**。
- **分页**：页长切片 DOM（`stealthPaginate.ts`：`fitPageEnd` / 页栈 / 预取）。悬停滚轮按视觉行；贴边再滚可切章（找书）。`Ctrl` / `Ctrl+Alt` / `Shift` / `Alt`+滚轮分别改字号 / 行间距 / 字体不透明度 / 背景不透明度。
- **无焦点翻页/切章**：Windows / Linux 默认 **`Control+Up/Down/Left/Right`**；macOS 默认 **`Control+Alt+Up/Down/Left/Right`**（Option，避开调度中心的 `⌃`+方向键）。与 `@shared/stealthNavShortcuts` 一致，可在摸鱼设置中改。已存且四键仍是旧 Mac 默认的，加载时升到新默认；改成其它组合的保留。退出键跟随主窗「摸鱼模式」。Linux Wayland 上全局键不可用。
- **右键**：最上方 **「定时滚动」**（Electron **`checkbox`**，运行中带勾）启动/停止；分隔线后 **「设置」** 开独立「摸鱼设置」窗；**「退出摸鱼模式」**。点窗外收起菜单时不翻页。
- **定时滚动**：行为对齐主窗（范围 **一屏** / **一行**，间隔毫秒；贴边再滚/翻则切章，无邻章则停止）。配置在摸鱼设置 **「定时滚动」** 页，写入 **`colorTxt.stealth.settings.timedScroll`**，**不与**主窗 `colorTxt.ui.settings.timedScroll` 互通。运行中改间隔、或手动翻页/滚行/切章，都会从当前时刻重新计满间隔。
- **偏好**：`colorTxt.stealth.settings`（字体 / **加粗** / **斜体** / 字号 / **行间距**（CSS `line-height` 倍数，默认 **1.4**）/ 颜色与不透明度 / 背景色与不透明度 / 离开隐藏 / **`timedScroll`** / 翻页切章快捷键 / 窗位置）。默认字体 **`system-ui`**、字号 16、字色 `#000000`、字体不透明度 1、背景 `#ffffff`、**背景不透明度 0.5**。设置窗与覆盖层经 `storage` 同步。设置窗标签为 **常规 / 定时滚动 / 快捷键**；快捷键列表/录制弹层样式对齐主窗 **`ShortcutPanel`**；录制打开时暂停全局键，**未关弹层直接关设置窗**时由主进程兜底恢复。
- **进度**：摸鱼期间不同步隐藏源窗；仅退出时 `jumpToLine`。找书换章时阅读进度走现有 `loadChapter`。
- **显隐热键**：摸鱼期间 `Ctrl+\`` 显隐覆盖层，并同步隐藏/显示**其它**主窗（如找书）；**不**把摸鱼源窗口 show 回来。

## 快捷键

- **动作与默认值**：`src/renderer/src/services/shortcutRegistry.ts` 定义动作 ID、说明、`scope`（`window` 窗口内 / `global` 系统级）及默认 Electron 快捷键字符串。含 **`toggleReaderEdit`**（默认 `Ctrl+/` / `Command+/`）、**`editSelectedText`**（默认 `Ctrl+E` / `Command+E`，无选区时无操作）、**`openSidebarSearch`**（默认 `Ctrl+Shift+F` / `Command+Shift+F`，仅主界面：打开侧栏「搜索」；阅读器有选区时自动填入并搜索）、**`openSidebarFiles` / `openSidebarChapters` / `openSidebarAiAssistant`**（默认 `Ctrl+Shift+E` / `C` / `A`，仅主界面：切到侧栏文件 / 章节 / AI 阅读助手）、**`toggleSidebar`**（默认 `Ctrl+B` / `Command+B`：普通模式切换侧栏；极简 / 全屏下只唤出浮动侧栏，不改开关状态）、**`toggleMinimalistView`**（默认 `F10`，进入/退出极简视图）、**`enterStealthReader`**（默认 **F9**，主界面与找书阅读器：进入摸鱼模式，见 **「摸鱼模式」**）与 **`toggleTheme`**（默认 `F2`，切换亮/暗主题色）。排版：**`decreaseLetterSpacing` / `increaseLetterSpacing`**（默认 `Ctrl+Shift+[` / `]`）、**`decreaseParagraphSpacing` / `increaseParagraphSpacing`**（默认 `Ctrl+;` / `'`）、**`decreaseHorizontalInset` / `increaseHorizontalInset`**（默认 `Ctrl+Shift+,` / `.`；Mac 为 `Command+…`，与系统设置 `Command+,` 不冲突）。
- **面板区分**：`ShortcutPanel` 的 `panelContext`（`main` / `findBook`）只影响列表展示；绑定仍共用完整 `shortcutBindings`。主窗不展示「书源管理」；找书窗不展示「打开文件 / 选择目录 / 章节匹配规则 / 添加/移除书签 / 侧栏搜索 / 侧栏文件 / 章节 / AI 阅读助手」。
- **持久化**：只把相对当前默认表有改动的项写入 `colorTxt.ui.settings.shortcutBindings`（见 `stores/cacheStore.ts` 与 `useAppPersistence`）；加载时与默认表合并、规范化（`shortcutUtils.mergeShortcutBindings`）。「全部还原默认」会写入空覆盖对象，清掉磁盘上的自定义项。
- **还原默认**：`ShortcutPanel` 中「全部还原默认」将 `shortcutRegistry` 的默认表写回并持久化（与 `App.vue` / `useAppPersistence` 联动）。
- **冲突与校验**：多个窗口级动作绑定同一快捷键时，由 `shortcutUtils.collectShortcutConflicts` 在确认前提示；**全局显隐**另须经主进程 `validateGlobalShortcut`（临时 `globalShortcut.register` 探测系统是否允许）。
- **窗口级**：`shortcutService.ts` 在 `window` 上监听 `keydown`（**捕获阶段**），将事件转为规范化快捷键并与当前 `ShortcutBindingMap` 比较。焦点在侧栏（`data-reader-sidebar-root`）内时**只让出**列表导航（`Up` / `Down` / `PageUp` / `PageDown` 对应的滚行/翻页）、**裸 `F2`**（文件列表重命名）以及侧栏输入框内的全部窗口快捷键；`F5` 打开设置等其它动作仍派发。**无修饰空格**另作「下一屏」硬编码别名（绑定表一动作只能绑一串，不能同时保留 `PageDown` 与空格）：与 `scrollPageDown` 走同一套 `preventDefault` / 朗读锁 / 蒙层让出；只读时**不**因焦点在顶栏/底栏按钮或侧栏列表而让出（空格不是列表导航键）。**编辑态**空格不翻页：输入面（编辑器 / 查找栏 / 输入框）打字，其它位置直接吞掉。用户若把空格绑到其它窗口动作，绑定表优先。找书主面板（无阅读器）关闭此别名。侧栏虚拟列表（章节 / 文件 / 搜索等）开启 **`VirtualList` `arrowNav`**：方向键与翻页焦点留在滚动容器上，避免虚拟行销毁后焦点落到 `body` 导致快捷键改去滚阅读区。**可点外关闭的弹出菜单**（`hasDismissibleOverlay`：顶栏「更多 / 字体 / 转换」、底栏路径/编码、侧栏「更多」等）打开时整表不接管，仅 **Esc** 由菜单关闭。有蒙版弹层时**不**整表跳过：仅不拦截会带动阅读器滚动/切章的项（`READER_SCROLL_SHORTCUT_ACTIONS`：行滚、翻页、上下章），交给弹层自己处理；`F2` 切换主题等其它动作仍生效。朗读中空格/左右在有蒙层时也不改道。
- **语音朗读中**：空格暂停/播放，左右方向键上一行/下一行（主界面与找书阅读器相同）。**`PageUp` / `PageDown` / 上下方向键 / 上下章 / 查找** 仍吞掉。查找栏等输入控件不拦截。详见 [语音朗读.md](./语音朗读.md)。
- **编辑态 Monaco 让出**：焦点在 **`ReaderMain` Monaco 根 DOM** 内且 **`readerEditMode`** 为 true 时，**`EDIT_MODE_MONACO_DEFERRED_ACTIONS`**（滚行、翻页、查找等）不拦截，交给编辑器 / 查找栏（见 **`shortcutService.ts`**）。
- **查找栏 ↑↓ 历史**：焦点在 **`.find-widget`** 内时，**`scrollUpLine` / `scrollDownLine`** 同样不拦截（只读模式必需；编辑模式与上条叠加）。详见 **「Monaco 查找栏」**。
- **UI 展示**：`App.vue` 将同一 `shortcutBindings` ref 传给 `AppHeader` → `MoreMenu`、以及侧栏活动栏；用户在快捷键面板修改并应用后，「更多」菜单项旁与图标按钮 `title` 中的快捷键会立即与持久化绑定一致。
- **配色弹窗**：动作 ID **`openColorScheme`**（默认 **F6**），由 `useAppWindowBindings` 注入的 `openColorScheme` 打开 `ColorSchemePanel`（与顶栏高亮菜单内「打开配色」一致）。
- **切换主题色**：动作 ID **`toggleTheme`**（默认 **F2**），与顶栏亮/暗图标按钮相同；主界面与找书窗口（含阅读器）均可用。
- **全局级（仅「阅读器显隐」）**：主进程 `globalShortcuts.ts` 注册 `globalShortcut`；渲染进程保存或校验时通过 `window.colorTxt.validateGlobalShortcut` / `setGlobalShortcut`（IPC 名 `shortcut:validateGlobalToggle` / `shortcut:setGlobalToggle`）与主进程同步；详见上文 **`globalShortcuts.ts`**。
- **录制与 IME**：
    - 编辑弹层打开时主进程 `suspendGlobalShortcutsForRecording`，关闭时 `resume`，避免录制时触发已注册的全局热键。
    - 同时由 `shortcutService.setWindowShortcutRecordingHandler` 接管 `bindAppShortcuts` 的 `window` 捕获监听：录制中不再匹配已绑定动作（如 `Ctrl+F` 查找），并 `stopImmediatePropagation`，避免组合键被拦截后输入框只剩下修饰键。
    - 录制界面不用 `<input>`，而用可聚焦的 `div` 只展示规范化快捷键，并加 CSS 闪烁光标。
    - `shortcutUtils.keyboardEventToAccelerator` 优先用 **`KeyboardEvent.code`**（物理键位）解析主键；`code === 'Unidentified'` 等情况下回退 **`keyCode`**，最后才用 `key`，避免 `Ctrl+Shift+2` 被显示成 `Shift+@`。
    - 忽略 `Process` / `Dead` / `Unidentified` 与 `isComposing` 等与 IME 相关的无效键。

## 数据存储说明

阅读进度口径说明：

- **展示口径（底栏 / 侧栏当前文件 /「更多-最近打开」当前文件）**：共用同一份运行时实时进度，基于编辑器视觉滚动位置（`scrollTop / maxScrollTop`）计算；到达底部时展示为 `100%`，并作为颜色切换为 `--success` 的依据。
- **恢复口径（重新打开同一文件）**：
  - 若 `file.meta` 中同时存在有效的 **`editorViewState`** 与 **`viewportTopPhysicalLine`**：流结束后 Monaco `restoreViewState` 并做锚点校验。
  - 若**仅有**有效 **`viewportTopPhysicalLine`**（如彩读书包「带阅读进度」导入后尚未产生 viewState）：按该物理行走 `restorePhysicalLine` / `scrollLineToBottom` 链路恢复。
  - 否则从**文首**打开。读入 meta 时若仅有 `editorViewState` 而无锚点，会丢弃该视图状态字段。
- **压缩空行与锚点兜底**：与 `editorViewState` 同时持久化 **`viewportTopPhysicalLine`**（保存时刻视口首行对应的源文件物理行号）。`restoreViewState` 后的 `nextTick` 内用 `getViewportTopLine` + `viewportDisplayLineToPhysicalLine` 校验当前首行物理行是否一致；不一致则按该物理行映射为显示行并 **`jumpToLine`**（使该行靠近视口顶部），避免仅依赖 Monaco 视图状态在滤空映射变化时出现错位。
- **恢复口径（重载当前正文 / 显式物理行）**：切换压缩空行、行首缩进、**转换**、改动「保留一个空行」/「章节标题上下保留空行」、应用章节匹配规则等触发**同路径重开**时，使用 `openFilePath(..., { restorePhysicalLine })`：取**视口末行**经 `viewportDisplayLineToPhysicalLine` 得到物理行，流结束后仍走 `scrollLineToBottom` 显示行对齐（与视图状态恢复互斥）。**仅切换转换**且不重开文件时走 **`applyReaderDisplayFromPhysicalLines`**（见 **「简繁与全半角转换」**）。
- **启动会话（`colorTxt.session`）**：若该路径在 `file.meta` 中已有 `editorViewState`+锚点，启动恢复时优先用它；否则若仅有 meta 锚点则按物理行恢复；再否则仍可用会话快照中的视口物理行作为后备（与 meta 独立）。
- **历史记录字段**：`progress` 与 `editorViewState` 均在 `file.meta` 持久化；`colorTxt.recent.files` 不存进度。当前打开文件的展示进度以运行时实时值为准。
- **macOS 全屏过渡**：进出系统全屏的动画帧不更新底栏进度，也不把漂掉的视口写入 meta；退出后按冻结的 `saveViewState` 复位。见 **「进入 / 退出全屏」**。
- **阅读位置就绪标志（`readingProgressSynced`，`App.vue` ref）**：
    - 无打开文件时为 `true`；每次 `resetSession`（打开/重开某路径）后为 `false`。
    - `file:stream-end` 处理中，在「完成滚动到恢复行 / 滚到底 / 或无需恢复仅 `emitProbeLine`」对应的 `requestAnimationFrame` + `nextTick` 之后再置为 `true`；`file:stream-error` 与「关闭当前文件」流程中也会恢复为 `true`（避免永久卡死写盘路径）。
    - 该标志表示「末行/进度是否已与视口对齐」，**不是**仅表示 `loading === false`（流结束到滚动完成之间仍可能为 `false`）。

**内存与快速重开（防进度被顶行污染）**：

- **阅读器 probe 与 `touchRecentFile` 解耦**：`useAppChapterNavigation.onProbeLineChange` 仍会更新 `lastProbeLine`、当前章高亮等；仅在 `readingProgressSynced === true` 时才调用 `touchRecentFile`（`updateMeta: false`），从而在加载与滚动恢复完成前**不**用视口行号写内存中的 `recentFiles` / meta。流结束置同步后会补一次位置快照（见 `useAppPersistence` 对 `readingProgressSynced` 的 watch）。
- **`touchRecentFile` 与打开瞬间**：在 `readingProgressSynced === false` 时，即使 `currentFile === path`，也**不**从 live 编辑器抓取 `editorViewState` / `viewportTopPhysicalLine`（显式传入除外），避免打开时顶部视口冲掉书包导入锚点等已写入 meta 的进度。
- **`rememberCurrentFileLine`**：在 `!readingProgressSynced` 时直接返回；否则 `touchRecentFile`（含当前 `saveViewState` 快照与进度）并 **`persistRecent` + `persistMeta`**，切书时把上一本书的 meta 写回内存与磁盘（`persistFileMeta` 仍受 `readingProgressSynced` 门控）。

**阅读进度：恢复 → 内存 → 存盘（无重复解析）**：

1. **恢复**：`openFilePath(path)` 按上方「恢复口径」设置 `pendingRestoreEditorViewState` / `pendingRestorePhysicalLine` / 锚点。显式 `options.restoreLine` / `restorePhysicalLine` 时清空视图状态待恢复并走物理行链路。
2. **打开时写 recent 盘**：`resetSession` 后 `touchRecentFile(path, true, { persistRecent: true, updateMeta: false })` 仅把路径顶到 MRU 并 `persistRecentFiles`；因进度未同步，**不**改写 meta 中的视口字段。
3. **滚动中**：仅 `readingProgressSynced` 后 `onProbeLineChange` 才 `touchRecentFile`（`updateMeta: false`），在内存中更新该路径的 `progress` + `editorViewState`，不写盘，关窗时 `flushRecentFilesAndFileMetaToDisk` 补齐。
4. **会话**：`persistReadingSessionSnapshot` 单独写 `colorTxt.session`（视口物理行），与 meta/recent 独立；若 meta 已有视图状态，启动恢复优先 meta。

**落盘时机（与 `useAppPersistence` 一致）**：

- `colorTxt.ui.settings` 在顶栏/侧栏偏好变更时即时写入（设置弹窗在点「确定」后才会写入）；**不含** API 密钥明文。
- **API 密钥保险库**：仅在设置 **确定**（AI → **`ai:config:set`**；语音 → **`persistVoiceReadSecretsToVault`**）或启动迁移时写入；**关窗** `persistWindowUnloadState()` **不写** `secrets.v1.json`，亦**不**整份回写 `colorTxt.ui.settings`。
- `colorTxt.session` 仅在窗口卸载相关路径与 `persistWindowUnloadState` 一并写入。
- `colorTxt.file.list` 在列表清空、移除项、选择目录合并、从会话恢复列表等变更时写入。
- `colorTxt.file.meta`：在离开当前文件（切书前的 `remember`、关闭当前文件）或窗口卸载等路径上会调用 `persistFileMeta`；**仅当「当前无打开文件」或 `readingProgressSynced === true` 时才会真正写入 localStorage**，否则跳过写盘，保留磁盘上上一份可靠数据。书签的增删改只先改内存，随上述路径落盘。
- `colorTxt.recent.files` 在打开新书（`persistRecent: true`）、切书前 `rememberCurrentFileLine`（同上）、以及窗口卸载 `flush` 时写入；条目仅为 `{ path }`。滚动阅读不修改 recent 顺序，仅改 meta 内存直至落盘。

### 数据管理（设置 → 常规）

「常规」页独立配置块；块内为左右布局：左侧 label **「数据管理」**，右侧 **「阅读数据」**（`icons.read`）+ **「清除缓存」**（`icons.clear`）；下方 hint 仍为「清除本地缓存数据（不影响界面相关的设置）。」。

#### 阅读数据面板

- **入口**：点 **「阅读数据」** → `ReadingDataPanel`（`AppOverlays`）。
- **列表**：`file.meta` 中满足 `metaHasClearableReadingData` 的路径（进度 / 书签 / 高亮 / 笔记 / 角色卡等）；列：复选框、文件名+路径、阅读进度（100% 用 `--success`，否则 `--warning`）、打开日期（`YYYY-MM-DD`）、删除（**`IconButton` `danger`**）。顶栏可过滤路径与排序（文件名 / 路径 / 进度 / 打开时间，默认打开时间降序）。虚拟列表带行间距（与侧栏 `itemGap` 同口径）。
- **选择**：资源管理器语义（单击 / Ctrl·Meta / Shift / Ctrl+A / Ctrl+I），见 `usePathListSelection`；底栏计数为 **`选中数/可见数`**（列表为空不显示）。**不**为 Shift 锚点项画高亮描边（与侧栏「文件」编辑多选一致）。
- **底栏说明**：按钮行上方提示清除阅读数据会抹除进度 / 书签 / 高亮 / 笔记 / 角色卡（含立绘）/ 最近打开 / AI 对话 / 向量与分词等痕迹；不删文件本身，不移出侧栏文件列表。
- **快捷键**：挂在 **`AppModal`** 蒙层捕获阶段 `@keydown`（见组件）；焦点在过滤输入框等可编辑控件内时**不**拦截（Ctrl+A 仍全选输入文本）。`maskClosable: false` 时点击蒙层会 **`focusBackdrop`**，便于随后用快捷键。
- **单项删除 / 底栏「删除」**：`clearReadingDataForPaths`——与底栏 **「清除阅读数据」** 同语义（含该书立绘目录，以及对应 AI 对话、向量索引与分词缓存）；不关闭当前打开文件；不删文件列表 / 收藏高亮词。流程：内存删除 meta 并移出最近打开 → **直接覆盖**写盘（不走合并）→ 他窗 `storage` 后以磁盘为准重载内存（本窗正在读且磁盘仍有的书仅盖回未落盘进度）。
- **「清除失效文件」**：对列表路径调用 **`file:stat`**；**`!isFile`** 视为失效（含磁盘上不存在：主进程对 ENOENT **不抛错**，返回 `isFile`/`isDirectory` 均为 false；亦含目录）。再对其调用 `clearReadingDataForPaths`；`stat` 期间 **`appLoading.with("检查中")`**。
- **底栏「清空」**：经 **`window.colorTxt.showMessageBox`** 确认后对列表全部路径调用 `clearReadingDataForPaths`；同样不碰会话 / 最近打开 / 文件列表 / UI 设置，不 reload。列表为空时「清空」「清除失效文件」禁用。

#### 清除缓存

- **作用**：点 **「清除缓存」**，经 **`window.colorTxt.showMessageBox`** 确认后：
  1. 设置 **`sessionStorage`** **`colorTxt.skipUnloadPersistence`**；
  2. 调用 **`ai:thread:deleteAll`** 清除全部 AI 对话（`threads` / `messages`）；
  3. 调用 **`ai:index:deleteAll`** 清除全部向量索引与分词缓存；
  4. 删除角色立绘缓存**根目录**（`characterPortraitCacheDir`，空则默认路径）；
  5. 从即将保留的 **`colorTxt.ui.settings`** 中去掉 **`highlightWordsByIndexGlobal`**（收藏高亮词）；
  6. `localStorage.clear()` 后写回处理后的 settings，并写回 **`colorTxt.ui.fontPickerDistinguishWeights`**、**`colorTxt.ui.systemFontFacePins`**（与界面字体偏好同类，清缓存后仍保留）；
  7. `window.location.reload()`。
- **会清**：会话、最近打开、文件列表、全部 `file.meta` 阅读数据、收藏高亮词、立绘文件、全部 AI 对话记录、向量索引与分词缓存等（以及其它非 settings 的 localStorage 键）。
- **不清**：电子书转换 `.md`、书包解压目录、找书下载目录、**`userData/ai/secrets.v1.json`** 与 AI **配置/密钥**等；界面设置（字号、主题、配色等）保留（除收藏高亮词字段）；系统字体列表模式与字重 pin 缓存同上。
- **为何需要 `sessionStorage` 标记**：
    - 窗口在 `pagehide` / `beforeunload` 时会调用 `persistWindowUnloadState()`，把内存中的会话、文件列表、最近打开和 meta 写回磁盘。
    - 若在 `localStorage.clear()` 之后直接刷新，卸载事件仍会执行，**会把清缓存前的内存状态再次写入**，导致「清不干净」。
    - 实现：清存储前设置 **`skipUnloadPersistenceSessionKey`**，使 **`persistWindowUnloadState()`** 在卸载时**直接返回**。关窗**不再**整份回写 `colorTxt.ui.settings`（界面设置仅在变更时落盘：设置「确定」、工具栏改字号等），避免本窗旧内存覆盖其它窗已保存值。
    - **多窗共用且不实时同步的字段**（阅读/编辑/语音/侧栏宽度等）：落盘时先读 localStorage 最新快照，仅把本窗相对打开/上次写入基线**有改动**的字段盖上去再写回；读到的快照**只用于拼写回盘，不合并进本窗内存**。语音方案在本窗有改动时仍按 id 与磁盘合并（保留它窗新增、落实本窗删除），合并结果同样不灌回本窗内存。
- **新页加载**：`initPersistenceBootstrap()` 开头会清除上述标记。

### 「重置当前页」与历史上的全量恢复默认

- **当前 UI**：设置弹窗 footer **「重置当前页」** 仅将**当前 tab** 内的草稿恢复为代码中的默认值（如常规页恢复启动选项/电子书目录/**书包解压目录**/章节字数等；阅读页恢复字号行间距/**段间距**/**字间距**/**粘性章节标题**/**中文换行优化**/平滑滚动/**滚动条轨道行为**/**定时滚动**等，并清 **`colorTxt.ui.fontPickerDistinguishWeights`** 为字体族、派发 **`colortxt:font-picker-list-mode-reset`**；**AI 阅读助手** 页另重置 **`tokenPricePerMillion`**、**`showTokenUsage`**、**`aiDataCacheDir`** 默认路径、**`wordcloudMaxWords`** 等，见 `SettingsPanel.resetAiDraft`；**向量模型** 页见 `resetVectorModelDraft`，恢复内置/远程默认与 **`builtinModelCacheDir`**），**不会自动落盘**——仍需点 **「确定」** 才会 `emit('apply')` 并持久化（AI 部分另走 `window.colorTxt.ai.configSet`）。找书窗口设置中的 **阅读 / 编辑 / 语音朗读** 与主界面共用 **`colorTxt.ui.settings`**（各窗内存独立，打开时读最后保存值）。
- **`skipSettingsPersistenceSessionKey`**：`useAppPersistence` 仍保留该 `sessionStorage` 门闩：若将来或脚本在**删除** `colorTxt.ui.settings` 后立刻触发其它路径上的 **`persistSettings()`**，应在此前写入该键为 `"1"`，否则会把内存中的旧 UI 设置写回，抵消删除操作。`initPersistenceBootstrap()` 启动时会清除该键与 `skipUnloadPersistenceSessionKey`。

## 预设字体与平台映射

预设项与 CSS `font-family` 栈定义在 `src/renderer/src/utils/presetFontDefinitions.ts`。菜单中的**显示名**与**实际族名**均随当前平台切换。系统字体列表、字重别名与启动 pin 见上文 **「阅读器字号…」→ 系统字体面板**（`systemFontFace.ts` / `systemFontCatalog.ts` / `systemFontFaces.ts`）。

下表中「族名栈」为按优先级排列的字体族（前者缺失时依次回退）。

| 类型             | macOS      | Windows    | Linux 等   | 族名栈（macOS / Windows / Linux）                                                                                          |
| ---------------- | ---------- | ---------- | ---------- | -------------------------------------------------------------------------------------------------------------------------- |
| 内置字体         | 京華老宋体 | 京華老宋体 | 京華老宋体 | 均为 `KingHwa OldSong`（`KingHwa_OldSong_3.0.ttf`）                                                                                 |
| 黑体 / UI 无衬线 | 苹方-简    | 微软雅黑   | 思源黑体   | `PingFang SC` → `Hiragino Sans GB` / `Microsoft YaHei` / `Noto Sans CJK SC` → `WenQuanYi Micro Hei` → `Source Han Sans SC` |
| 宋体 / 明体      | 宋体-简    | 宋体       | 思源宋体   | `Songti SC` → `STSong` / `SimSun` / `Noto Serif CJK SC` → `Source Han Serif SC`                                            |
| 楷体             | 楷体-简    | 楷体       | 文鼎 UKai  | `Kaiti SC` → `STKaiti` / `KaiTi` / `AR PL UKai CN` → `Noto Serif CJK SC`                                                   |

说明：

- 名称中的「**-简**」表示对应 **简体中文（SC）** 字体族，与 macOS 字体册中常见命名一致；并非「只能显示简体字」，而是字形与排版习惯面向简体场景。
- **Linux** 等环境需自行安装常见中文字体包（如 Noto CJK、文泉驿、文鼎 UKai 等），否则可能回退到栈中后续族名或系统默认字体。
- **内嵌京華老宋体与选区**：`@font-face` 加载的同款 TTF 会被 Monaco 判成等宽，纯 ASCII 行用 `spaceWidth × 列` 画选区，拉丁字母实际非等宽时会左偏；行内有全角字则走 DOM 测量故正常。系统安装的同名字体常因伪斜体/粗体字宽不一致而被判非等宽。阅读器 **`disableMonospaceOptimizations: true`**（`buildReaderEditorSharedCoreOptions`）。
