# 语音朗读

> 与 [开发构建.md](./开发构建.md) 中的 `src/main/voiceRead/` 目录树互为参照。

## 语音朗读

**多 TTS 引擎 Provider**（含 **小米 MiMo**、**火山引擎**）、**多套朗读方案**、**单音色 / 旁白·对白多音色**、**AI 说话人识别**（可选 **情绪标注**）与 **角色专属音色**，以及独立于方案的 **朗读过滤 / 自动暂停**；与 [开发构建.md](./开发构建.md) 目录树、**`src/main/voiceRead/`**、**`useAppVoiceRead.ts`** 互为参照。

### 功能与入口

| 项目 | 说明 |
| ---- | ---- |

### 朗读设置（过滤与自动暂停）

独立于朗读方案；草稿在面板内编辑，点 **保存** 才落盘。主界面挂在 **`AppOverlays`**，找书挂在 **`FindBookPanel`**。

| 项目 | 说明 |
| ---- | ---- |
| 持久化 | **`colortxt:voiceReadSpeak`**（`constants/voiceReadSpeak.ts` / **`voiceReadSpeakStore.ts`**）；变更广播 **`colortxt:voice-read-speak-changed`**。不写入 `colorTxt.ui.settings.voiceRead` |
| UI | **`VoiceReadSpeakSettingsPanel.vue`**：自动暂停分段按钮；过滤规则表（启用开关、名称、规则、拖动排序 / 编辑 / 删除）；**添加过滤规则** / **恢复默认过滤规则**；编辑规则可用 **全屏编辑器**（`BookSourceFieldMonacoModal`，与替换规则相同） |
| 默认规则 | 全部默认**关闭**：小括号内、中括号内、大括号内、尖括号内、加粗、斜体（正则；ASCII `]` 在字符类中须转义） |
| 过滤 | **`voiceReadFilterApply.ts`**：已启用规则按 `order` 套用；正则编译 **`gums`**（`.` 跨行，`^`/`$` 仍按行）；命中段非换行字符换成空格、换行保留。朗读时先把全文按行拼接再匹配，以便括号等内容跨行；合成前过滤 TTS 文本，**AI 说话人识别仍用原文**。过滤指纹变化会清合成缓存 |
| 自动暂停 · 章节数 | 主窗按侧栏章节列表计章（无目录则整文件 1 章）；找书按文档/自动续章。从某章中间开始，当前章算 1 章；即将进入第 N+1 章时暂停。换章在**当前朗读行**变化时立刻计（不要等整批播完）。播放 / 上一行 / 下一行会重置；重新合成、找书自动续章不重置 |
| 自动暂停 · 时长 | 累计**实际出声**时间（暂停不计）。到点走与手动暂停相同的路径，toast「已自动暂停朗读」 |
| 底栏 | 自动暂停已开且 **正在播放** 时，**阅读进度**左侧显示 **`语音朗读：…`**（**`voiceReadFooterStatus`**）：章节为剩余 `M/N`（如 `5/5`→`4/5`）；时长为剩余时钟（不足 1 小时 `mm:ss` 如 `30:00`→`29:59`，满小时 `h:mm:ss` 如 `2:58:02`）。暂停 / 停止后不显示（继续播放会重置倒数） |

### TTS 引擎（`@shared/voiceReadEngines`）

主进程 **`voiceRead/providerRegistry.ts`** 统一 **`synthesize` / `listVoices` / `healthCheck`**；渲染侧经 **`voiceReadSynthesisClient.ts`** → preload IPC。

| 引擎 id | 显示名 | 实现 | 密钥 | 音频 | 说明 |
| ------- | ------ | ---- | ---- | ---- | ---- |
| `edge` | Edge TTS | **`edgeProvider`** + **`voiceReadEdgeTts.ts`** + **`voiceReadEdgeTtsDrm.ts`** | 无 | MP3 | 微软 Read Aloud Neural 语音；WebSocket 握手用 **Sec-MS-GEC v2**（见下）；静态音色表 **`voiceReadEdgeTtsVoices.ts`**（与鉴权无关，音色 ID 未改） |
| `system` | 系统语音 | 渲染进程 Web Speech API | 无 | MP3 | 离线；**`speechSynthesis`** 动态枚举（Windows 上多为 OneCore，**看不到** SAPI5 / NaturalVoiceSAPIAdapter 自然语音） |
| `winSapi` | 讲述人自然语音 | **`winSapiProvider`** + **`voiceReadWinSapi.ts`**（PowerShell `System.Speech`） | 无 | WAV | **仅 Windows**；枚举/合成经典 **SAPI5** 音色（含 NaturalVoiceSAPIAdapter 注册的讲述人/Edge 自然语音）；串行合成；设置页动态 **`listVoices`** |
| `dashscope` | 阿里云通义 | **`dashscopeProvider`** | **`engineConfig.dashscopeApiKey`** | PCM | Qwen3-TTS；默认模型见 **`voiceReadDashscopeModels.ts`**（含 **`qwen3-tts-instruct-flash`**）；支持 Instruct 自然语言语气 |
| `minimax` | MiniMax | **`minimaxProvider`** | **`engineConfig.minimaxApiKey`** | MP3 | 动态 **`listVoices`**（系统 / 快速复刻 / 文生音色）；默认 TTS 模型见 **`voiceReadMinimaxModels.ts`** |
| `mimo` | 小米 MiMo | **`mimoProvider`** | **`engineConfig.mimoApiKey`** | MP3 | 三模型：**`mimo-v2.5-tts`**（预设音色）、**`-voicedesign`**（VoiceDesign 声音描述）、**`-voiceclone`**（VoiceClone 参考音频）；预设音色见 **`voiceReadMimoVoices.ts`**；参考音频 Base64 缓存。Base URL 按密钥前缀自动选择：`sk-` → **`api.xiaomimimo.com`**，`tp-` → Token Plan 中国集群 **`token-plan-cn.xiaomimimo.com`**（**`resolveMimoApiBaseUrlFromApiKey`**） |
| `volcengine` | 火山引擎 | **`volcengineProvider`** | **`engineConfig.volcengineApiKey`** | 默认 24 kHz PCM（可改） | **豆包语音合成大模型 2.0**；新版 `X-Api-Key` 鉴权，请求固定携带 **`X-Api-Resource-Id: seed-tts-2.0`**；`audio_params.speech_rate` 承接应用语速；音调写入 **`additions.post_process.pitch`**（**`engineConfig.volcenginePitch`** 整数 [-12, 12]，0 为默认且不传）；**`engineConfig.volcengineSampleRate`** 可选 8–48 kHz；多语种/方言按朗读槽位（单音色 / 旁白 / 对白 / 男声 / 女声）写入 **`volcengineSlotSpeechModes`**，合成时带上 **`volcengineSpeechSlot`** 后写入 `additions.explicit_language` / `explicit_dialect`（音色表标了方言的可指定，如 Vivi / 小何 / 云舟 / 小天；指定非中英混语种时不带方言）；合成经 **`volcengineSynthQueue`** 限流；静态音色表 **`voiceReadVolcengineVoices.ts`** 收录官方 2.0 主表 293 个 + 多语种表 151 个，共 **444 个唯一音色**，含中文、英文和其他多语种 |

通义 / MiniMax / MiMo 设置页的 **`AppConnectionTestButton`** 仅校验密钥、**不合成**。火山引擎官方单向流式接口**没有**单独的无用量鉴权探测：连接测试会使用默认音色合成一个汉字（8 kHz 以减小下行），因此会产生极少量用量。

### Edge TTS 接入（Sec-MS-GEC v2）

Edge Read Aloud **无需用户 API Key**；合成走 Bing 消费端 WebSocket（`speech.platform.bing.com/.../readaloud/edge/v1`），查询参数携带固定 **`TrustedClientToken`** 与动态 **`Sec-MS-GEC` / `Sec-MS-GEC-Version`**。

| 项目 | 说明 |
| ---- | ---- |
| 鉴权 | **`voiceReadEdgeTtsDrm.ts`**：生成 **Sec-MS-GEC v2**（格式 `<16 hex>-<64 hex>`，对齐 [edge-tts](https://github.com/rany2/edge-tts) ≥7.3 的 `drm.generate_sec_ms_gec_v2`）；版本串为 **`2-{ChromiumFullVersion}`**。旧版 v1（纯 SHA-256、版本前缀 `1-`）会被服务端拒绝，握手 **403** |
| 时钟 | 403 时解析响应 **`Date`** 校正本地时钟偏差后重试（同 edge-tts）；无音频 / WebSocket / 超时亦自动重试（最多 3 次） |
| 合成 | **`voiceReadEdgeTts.ts`**：SSML + `speech.config`（开启 WordBoundary）→ 收 MP3；协议与音色表未因 v2 鉴权变更 |
| 音色 | 静态表 **`@shared/voiceReadEdgeTtsVoices.ts`**，可由 **`scripts/generate-edge-tts-voices.mjs`** 从官方 voices/list 重新生成；**本次鉴权升级不改音色列表** |
| 单测 | **`voiceReadEdgeTtsDrm.test.ts`**（固定时间窗口向量与 edge-tts 一致；纳入 **`npm test`**） |

### 标点停顿（仅 Edge TTS）

Edge 的 readaloud 端点**不支持** SSML `<break>`（带上后服务端直接断连、无音频返回），改走元数据方案：

| 项目 | 说明 |
| ---- | ---- |
| 位置 | 主进程 **`voiceReadEdgeTts.ts`** 收集 `audio.metadata` 中的 **WordBoundary**，映射逻辑在 **`@shared/voiceReadPunctuationPauses`**：按词序把全角标点段映射为音频内待替换区间 `[fromMs, toMs]`（标点前语音结束 → 标点后语音开始，含标点词自身音频）；词与标点粘在同一 WordBoundary 时按文本比例插值。段尾标点从末词末尾延伸到音频总长。连续标点合并为一段（句末优先，如「……，」算句末）；`。」`等右引号并入同段。ASCII 标点不参与，避免数字 `12.5`、URL、英文缩写误伤 |
| 传输 | 区间随 mp3 一并返回（**`VoiceReadSynthesisResult.pauses`**，`VoiceReadPausePoint`），经 IPC / 合成缓存原样携带；**区间只依赖音频内容，与停顿时长解耦**，调整滑块不失效已缓存的音频 |
| 播放 | **`voiceReadLinePlayer.ts`** `decodeAudioData` 后把区间整体**替换**为干净静音（边缘 2ms 淡入淡出；重叠 / 相邻区间合并，取最宽区间 + 最长停顿），再排播；时长取当前设置值并 **除以语速**（2x 时停顿减半） |
| 设置 | **`pauseSentenceMs`**（句末 `。！？…`，0～1200）/ **`pauseCommaMs`**（句中 `，；：、`，0～600），默认 **`0` 关闭**（老存档无字段保持原听感）。引擎开关 **`supportsPunctuationPauses`**（目前仅 `edge`），设置页按其显隐 |

### 朗读方案（`voiceReadProfiles`）

与对话 **`chatProfiles`** 类似，**最多 12 套**独立命名方案（**`@shared/voiceReadProfiles`**、**`useVoiceReadProfileDraft.ts`**）。

| 项目 | 说明 |
| ---- | ---- |
| 持久化 | **`colorTxt.ui.settings`** → **`voiceRead`**（引擎、方案 id、单/多音色字段；**不含**密钥明文；根级 **`engineConfig`** 亦剥密钥；**不含**过滤 / 自动暂停，见 **「朗读设置」**） |
| 活跃方案 | **`activeVoiceReadProfileId`**；设置 **确定** 后写入运行时快照，并 **`persistVoiceReadSecretsToVault`** 写保险库 |
| 方案内容 | 引擎 id、**`engineConfig`**（模型名、火山 **`volcengineSampleRate`** / **`volcenginePitch`** / **`volcengineSlotSpeechModes`**）、**`scheme`**、单音色 **`single.voiceId`** 或多音色 **`multi.*`** |
| API 密钥 | 各方案 **`dashscopeApiKey` / `minimaxApiKey` / `mimoApiKey` / `volcengineApiKey`** 加密存 **`voiceRead.profileKeys`**（JSON，按 **profileId** 索引）；**关窗不写**；与 AI 对话/文生图分槽 |

### 单音色 / 旁白·对白多音色（`scheme`）

| `scheme` | 说明 |
| -------- | ---- |
| **`single`** | 全书一段音色朗读 |
| **`multi`** | 旁白 + 对白分轨：可设旁白、默认对白、**男声对白**、**女声对白**；**对白引号样式**（`""` / `''` / `「」` / `『』` 多选） |
| **AI 识别** | 多音色 + **AI 阅读助手已启用** 时可开 **`aiSpeakerRecognitionEnabled`**：朗读前主进程 **`attributeVoiceReadSpeakers`** **按行**识别说话人姓名、性别与情绪（输入为当前行原文 + 角色表姓名/别名 + **邻近参考行**：向两侧穿过纯对白行至首个非纯对白行后再多收一行，中间纯对白保留，单向最多约 15 非空行；**不**做全书向量检索；结果缓存于 **`voiceReadSpeakerCache.ts`**，缓存键含上下文）；匹配角色 **`voiceReadVoiceId`**（含其语种/方言）或按男女声回退；消耗对话 Token（可展示在设置/侧栏） |
| **情绪标注** | AI 识别开启且引擎/模型支持时，可开 **`emotionEnabled`**（默认 true）；关闭则合成时不传情绪。通义 **`qwen3-tts-instruct-flash`** / MiMo：AI 输出 **10～30 字自然语言** 语气描述 → **`mapEmotionForNaturalLanguageEngine`**（通义 `instructions` / MiMo user 消息）。火山 2.0：**`mapEmotionForVolcengine`** 改成对话式指令（如「你可以用关切、略带担忧的语气说话吗？」）写入 **`additions.context_texts`**（官方仅此字段；不写 `req_params` 顶层 `context_texts`，也不用 1.0 多情感音色的 **`audio_params.emotion`**）。MiniMax：固定 **9 枚举**标签，无法映射则不传 |

渲染侧 **`voiceReadLineBuild.ts`** 切段、**`voiceReadVoiceResolve.ts`** 解析每段 voiceId（**`voiceReadEmotionActive`** 控制是否写入 `chunk.emotion`）；**`voiceReadLinePlayer.ts`** 统一缓存与 IPC 合成入口（缓存键含 **`speechSlot` + language + dialect**）。

### 火山引擎语种 / 方言

官方 `additions` 为 **JSON 字符串**。不传 `explicit_language` = **中英混**；`explicit_dialect` 仅在中英混时发送。官方文档写方言「仅 Vivi」，控制台与音色表对 **Vivi / 小何 / 云舟 / 小天** 等均标了方言，应用以音色表为准。

| 来源 | 持久化 | 合成 |
| ---- | ------ | ---- |
| 设置页各槽位 | **`engineConfig.volcengineSlotSpeechModes`**（`single` / `narration` / `dialogue` / `dialogueMale` / `dialogueFemale`） | 请求 **`volcengineSpeechSlot`**，语言/方言字段 **`undefined`**（走槽位） |
| 角色卡专属音色 | 角色 **`voiceReadLanguage` / `voiceReadDialect`**（仅当设了 **`voiceReadVoiceId`**） | **`speechSlot` 为空**，请求带上语言/方言（`""` = 显式中英混/默认方言；**不要**把 `undefined` 归一成 `""`，否则会冲掉槽位配置） |

UI：**`SettingsVolcengineVoiceSpeechMode.vue`**（设置页嵌在各音色下；角色卡抽屉「语音」与「台词」之间）。换音色会清空该处语种/方言。

### API 密钥分开存储（通义 / MiniMax / MiMo / 火山引擎）

同一开放平台账号可复用，但应用内**分槽**保存，互不同步。正式密钥进入系统凭据库，并以加密数据落在 **`userData/ai/secrets.v1.json`**（见 **「API 密钥保险库」**）；包括火山 `volcengineApiKey` 在内的密钥均会在设置快照写盘前剥离，**不会写入 `localStorage` 或 `config.json`**。

| 功能 | 设置页 | 保险库 slot / 字段 |
| ---- | ------ | ------------------ |
| 语音朗读 · 通义 TTS | 语音朗读 | **`voiceRead.profileKeys`** → 方案 `dashscopeApiKey` |
| 语音朗读 · MiniMax TTS | 语音朗读 | **`voiceRead.profileKeys`** → 方案 `minimaxApiKey` |
| 语音朗读 · MiMo TTS | 语音朗读 | **`voiceRead.profileKeys`** → 方案 `mimoApiKey` |
| 语音朗读 · 火山引擎 TTS | 语音朗读 | **`voiceRead.profileKeys`** → 方案 `volcengineApiKey` |
| AI 对话 · MiniMax | AI 阅读助手 | **`ai.chatProfileKeys`** → 方案 `apiKey` |
| AI 对话 · 小米 MiMo | AI 阅读助手 | **`ai.chatProfileKeys`**（与 MiMo TTS 分开） |
| 文生图 · MiniMax | 角色卡 | **`ai.txt2imgProfileKeys`** |

| 向量嵌入 · 远程 API | 向量模型 | **`ai.embedding.apiKey`** |
